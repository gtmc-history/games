## §1 ROLE_LOCK · 3행 게이트 · TITLE_LOCK · 시점 시각화

### ROLE_LOCK
- **플레이어**: 오늘날의 역사 잡지 편집부 자료 담당자
- **과제**: 「1920~1930년대 조선 경제는 어떻게 변했는가」 특집의 제목과 설명을 완성한다
- **게임 유형**: 탐구자 게임 (saito1919 계열). 단, 판단 대상이 다르다 — saito1919는 **사료의 신뢰도**를, economy1930은 **설명의 충분성**을 판단한다. 탐구자 게임 포맷 피로 관리 시 이 축으로 구분할 것.
- **불확실성의 원천**: 자료가 순차적으로 공개되기 때문에 처음에는 일부 사실만 안다 (연출이 아니라 역사 탐구의 조건)
- **하지 않는 것**: 당대 기자 재현 / 기사 게재 가능성 / 검열 / 정책 결정 시뮬레이션

### 3행 설계 게이트 (확정)
- **발견 한 문장 (교사용)**: 생산·투자·공장이 증가했다는 사실과 식민지적 수탈 구조는 서로를 부정하지 않는다. 경제를 판단하려면 성장의 크기뿐 아니라 생산물의 흐름, 소유, 이익과 비용의 분배, 권리가 반영되는 조건을 함께 보아야 한다.
- **발견 한 문장 (학생 노출용)**: ▸ 숫자가 늘었다는 것만으로는 누구의 삶이 나아졌는지 알 수 없다.
- **플레이 동사**: **고쳐 쓴다** (자료가 늘 때마다 기사 문장을)
- **선택의 이유**: 자료가 늘어날 때마다 기존 판단이 충분한지 다시 결정해야 하기 때문

### TITLE_LOCK
- 게임 제목: **《숫자는 성장하고 있습니다》** — 시작부터 공개, 결말 교체 없음
- 제목의 복선성 허용: 게임 전 "지표가 성장하는 게임인가?" → 게임 후 "숫자는 성장했다. 무엇이 빠져 있었나?"로 재독해되는 장치
- **학생이 고쳐 쓰는 대상은 게임 제목이 아니라 자신의 특집 기사 제목이다** (혼동 금지)

### 시점 시각화 원칙 (팔레트 LOCK)
현대의 탐구자가 과거 자료를 검토한다는 구조를 유지하기 위해 **현대 편집부 UI와 역사 자료 카드를 시각적으로 분리**한다. 시대 팔레트는 게임 전체가 아니라 **역사 자료 레이어에만** 적용한다.

| 레이어 | 역할 | 시각 |
|---|---|---|
| 현대 편집부 | 조작부: 자료 요청·문장 수정·최종 제목 | 밝은 중립 배경, 현대적 그리드, 산세리프(Noto Sans KR) |
| 역사 자료 카드 | 1920~30년대 자료 표시 | 약한 세피아(`--color-sepia: #8b7355` 계열), 종이 질감, 연도·출처 표식, Gowun Batang |

- 세피아는 분위기가 아니라 **자료의 출처 시점을 표시하는 기능적 표식**으로만 사용 (SKILL §0-1 연출-기능 종속의 레이어 단위 적용 — 첫 사례)
- 태극 청홍 미사용. 특히 R4 일본/조선 비교를 청/홍으로 구분하지 않는다 (가치 판단 색 오독 위험)
- 정오 연출(초록/빨강)은 전 장면 미사용 — §3의 피드백 열 참조. correct-pulse / wrong-shake 애니메이션 자체를 코드에 포함하지 않는다.

### 진행 구조 (점층 LOCK)
**받는다(R1) → 요구한다(R2) → 우선순위화한다(R3) → 비교한다(R4) → 종합한다(FINAL)**
라운드마다 학생의 능동성이 한 단계씩 상승. 반복이 아니라 점층.

## §3 판단 설계 표 + 선택지 전문

### 3-1. 구조 표

| 판단 ID | 학생 행위 | 행위 유형 | 층위 | 피드백 방식 |
|---|---|---|---|---|
| `S0_INITIAL` | 최초 기사 제목 선택 | 판단 | 해석 | 없음 · 저장만 |
| `R1_FIRST` | 쌀 자료로 첫 문장 선택 | 판단 | 해석 | 즉시 없음 → 추가 자료 대조 |
| `R1_REVISION` | 문장 유지/수정 | 판단 | 해석·평가 | 자료 대조 / 평가 기준 질문 |
| `R2_REQUEST` | 확인할 자료 선택 | 자료 탐색 | 해당 없음 | 정오 없음 · 순서 저장 |
| `R2_REVISION` | 「회사가 증가했다」 충분성 판단 | 판단 | 해석 | 충분성 대조 |
| `R3_ORDER` | 자료철 4종 열람 순서 | 자료 탐색 | 해당 없음 | 정오 없음 · 순서 저장 |
| `R3_JUDGMENT` | 흥남 개발 판단 | 판단 | 해석·평가 | 조건·대가 제시 |
| `R4_COMPARE` | 일본/조선 차이 설명 | 판단 | 해석 | 비교 패널 자료 대조 |
| `FINAL_TITLE` | 최종 제목 확정 | 판단 | 종합 평가 | 사용 근거 표시 · 정오 없음 |

- **행위 유형 `자료 탐색`은 층위 판정 대상이 아니다.** 원칙 ⑦(사실/해석/평가)은 `판단` 행위에만 적용.
- **정오 판별형 선택 없음** → SKILL §2-3 정오 피드백 전 장면 미사용. 판단 선택지에 사실 오류를 넣지 않는다는 원칙(§8 거부 로그 참조)의 귀결.

### 3-2. 선택지·피드백 전문

#### S0_INITIAL — 도입
편집장 대사:
▸ 1920년 이후 조선 경제는 크게 변했습니다. 「지난 15년, 조선 경제는 어떻게 변했는가」 특집을 완성해 주세요.

초기 카드 3장 (요약 층):
▸ 농업 — 쌀 생산 증가
▸ 기업 — 회사·자본 증가
▸ 공업 — 공장·도시 성장

질문: ▸ 지금 보이는 자료만으로 제목을 정한다면?
- ① ▸ 조선 경제, 성장의 길에 들어서다 → 저장값 `growth`
- ② ▸ 농업과 공업 개발이 본격화되다 → `development`
- ③ ▸ 성장은 보인다. 혜택이 누구에게 갔는지는 더 봐야 한다 → `distribution`
- ④ ▸ 이 자료만으로는 평가하기 어렵다 → `reserve`

피드백 없음. FINAL에서 재등장.

#### R1_FIRST — 쌀은 늘었습니다
자료 카드(역사 레이어, 자체 그래프):
▸ 쌀 생산량 — 1920년 약 1,488만 석 → 1930년 약 1,918만 석

질문: ▸ 기사의 첫 문장을 골라 주세요.
- A ▸ 산미 증식 계획 아래 쌀 생산량이 증가했다
- B ▸ 생산이 늘었으니 조선인의 식생활도 나아졌을 것이다
- C ▸ 생산량만으로는 농민 생활을 판단할 수 없다
- D ▸ 얼마나 생산됐는지와 함께 어디로 갔는지도 봐야 한다

즉시 피드백 없음 → 추가 자료 자동 도착 (이 라운드만. 게임 규칙 학습 구간).

직원 대사: ▸ 잠깐만요. 생산량만 보면 될까요? 이 자료도 확인해 보세요.

추가 자료 카드:
▸ 일본 반출 — 생산이 계획에 못 미쳤는데도 반출은 예정대로 진행
▸ 한국인 1인당 쌀 소비량 감소
▸ 수리조합비·비료 대금·소작료 등 농민 부담 증가

#### R1_REVISION — 유지/수정
질문: ▸ 처음 고른 문장을 어떻게 하시겠습니까?
- **그대로 둔다** → 불이익 없음. 추가 자료와의 관계만 표시: ▸ 이 문장은 새 자료와 어떻게 연결됩니까? 결과 화면에서 다시 확인합니다.
- **고쳐 쓴다** → 아래 3안 제시
  - A ▸ 생산이 늘었으므로 농민 생활도 나아졌다
    - 피드백(자료 대조): ▸ 소비 감소와 부담 증가 자료는 이 문장으로 설명되지 않습니다.
  - B ▸ 생산은 늘었지만 반출과 부담까지 봐야 생활을 판단할 수 있다
    - 피드백(자료 연결): ▸ 생산·반출·소비·부담 네 자료가 모두 문장에 연결됩니다.
  - C ▸ 농민 생활이 어려워졌으니 산미 증식 계획은 실패한 정책이다
    - 피드백(평가 기준 질문): ▸ 무엇을 기준으로 한 실패입니까? 생산 확대와 생활 개선은 같은 기준일까요?

> C 처리 원칙: "생산 증가가 없었다"가 문제가 아니라 **'실패'라는 평가를 기준 제시 없이 사실 서술과 한 문장에 섞은 것**이 문제 (원칙 ⑦). 오답 낙인 없이 기준을 되묻는다.

렌즈 1 획득: ▸ 🔎 생산물은 어디로 갔는가?

#### R2_REQUEST — 회사는 늘었습니다
자료 카드:
▸ 1920년 회사령 폐지 — 회사 설립 허가제에서 신고제로
▸ 일본 자본의 투자 증가, 한국인의 회사 설립도 증가

질문: ▸ 「회사가 늘었다」를 기사로 쓰기 전에, 무엇을 먼저 확인하시겠습니까?
- ① ▸ 한국인·일본인 회사의 자본금 → `capital`
- ② ▸ 1923년 관세 제도의 변화 → `tariff`
- ③ ▸ 한국인 회사의 규모 → `kr_scale`

선택 순서 저장. **선택하지 않은 자료도 이후 전부 열람** (핵심 증거 잠금 금지).

자료 내용:
- `capital` ▸ 일본인 회사의 자본 규모가 한국인 회사보다 훨씬 컸다 (자체 재시각화 그래프)
- `tariff` ▸ 1923년 일본 상품 관세 폐지 — 값싼 일본 상품이 들어와 한국인 기업의 경영이 어려워졌다
- `kr_scale` ▸ 한국인의 회사 설립도 늘었지만 대부분 규모가 작은 회사였다

> 세 자료의 역할 분담: 자본 격차 / 경쟁 조건 / 한국인 기업 성장의 한계. 원안의 `invest`(일본 자본의 진출)는 첫 카드와 정보 중복으로 기각 — §8 로그 참조. `kr_scale`은 교과서 서술 근거로 B등급 복원 (감사 완료 주체: 찰리쌤 교과서 문면 확인, v1.1 잠금 전 필수). 업종 분포는 계속 보류.

#### R2_REVISION — 충분성 판단
질문: ▸ 「회사가 증가했다」 — 이 문장으로 충분합니까?
- A ▸ 충분하다. 기업 활동이 활발해졌고 한국인 기업도 함께 성장했다
  - 피드백(자료 대조): ▸ 자본금 격차와 관세 폐지 자료가 '함께 성장'과 충돌합니다.
- B ▸ 사실이지만 부족하다. 소유와 자본 규모를 함께 써야 한다
  - 피드백(자료 연결): ▸ 회사 수·자본금·관세 자료가 한 문장으로 이어집니다.
- C ▸ 일본 자본의 확대를 중심으로 설명해야 한다

## §4 사료 등급표

| 등급 | 정의 | 이번 게임 해당 자료 |
|---|---|---|
| **A** | 당대 1차 사료를 원문·원자료로 직접 대조 확인 | 현재 없음 |
| **B** | 교과서·학술서가 인용한 통계·서술 (원자료 미대조) | 쌀 생산량 수치(1,488만→1,918만 석), 반출·소비 감소 서술, 회사령 폐지·관세 폐지, 자본금 격차, 흥남 공업화, 노동 차별·공장법 미적용, 주민 저항·경찰 진압, 폐수·어류 폐사, 만평 내용 |
| **C** | 문학 자료 등 성격이 다른 자료 — 통계로 사용 금지, 출처 성격 표시 필수 | 소설 『질소 비료 공장』 발췌 요지 |

- **교과서 인용 통계는 원자료 직접 대조 전에는 A로 올리지 않는다** (회사령 게임에서 확립한 원칙 유지).
- 게임 내 표시 (M3 확정): **학생 화면에는 A/B/C 등급 문자를 노출하지 않는다** — 등급은 설계·감사용 메타데이터로 코드 주석(`data-grade`)과 본 문서에만 유지. 학생에게는 자료 성격 태그만 표시: `교과서 수록 통계` / `교과서 서술` / `문학 자료` / `만평 내용 재구성`. 문학 카드는 `통계 아님` 안내 병기.
- **감사 항목 처리 (v1.1 — 2026.8.22 감사 완료)**: 한국인 회사의 **규모** — ✅ **B등급 확정**. 찰리쌤 교과서 문면 확인 완료: "한국인의 회사 설립도 증가했으나, 규모가 작은 회사가 대부분이었다" + 이어지는 1923년 관세 폐지 서술. `kr_scale` 카드 문구는 교과서 문면을 벗어나지 않음. 한국인 회사의 **업종 분포** — 해당 문면에서 확인되지 않음, **보류 유지·게임 추가 금지**.
- 도판 전면 재구성: 쌀 그래프·자본금 그래프 → 자체 SVG / 만평 → 텍스트 비교 패널 / 문학 자료 → 요지 요약. **교과서 도판 원본은 게임 자산으로 사용하지 않는다.**
