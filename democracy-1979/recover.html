1979 역사 판단 기록 복구

게임을 다시 할 필요 없이, 이전 수업의 크롬에 남은 판단 기록을 서버로 전송합니다.

1. 브라우저 기록 확인

지난 수업과 같은 크롬북·같은 크롬 프로필에서 열어야 합니다.

기록을 확인하는 중입니다.

확인 중과거 전송 표시
    활동을 아직 마치지 않았습니다. 먼저 원래 게임에서 이어하기로 완료한 뒤 이 페이지로 돌아오세요.
    기록을 찾지 못했습니다. 다른 크롬 프로필이나 시크릿·게스트 모드였는지 확인하세요. 사이트 데이터가 삭제된 경우 이 페이지에서 되살릴 수 없습니다.

    2. 서버로 기록 다시 전송

    기존 판단 내용은 변경하지 않습니다. 이미 전송했던 기록도 중복 등록되지 않도록 보호합니다.

    완료된 기록과 학급을 확인하면 전송할 수 있습니다.

    자동 전송은 하지 않습니다. 제출 버튼을 눌러야 서버에 전송됩니다. 저장 성공 또는 이미 접수된 기록이라는 안내를 확인하세요.

    복구할 때 주의할 점

    • 원래 게임에서 새로 시작·기록 삭제를 누르지 마세요.
    • 크롬의 인터넷 사용 기록 중 사이트 데이터를 삭제하지 마세요.
    • 서버 전송이 실패하면 JSON 백업을 담임·교과 선생님께 안전한 방법으로 제출하세요. JSON에는 직접 작성한 답변이 포함됩니다.
    • 학급만 수집하며 이름·학번은 요구하지 않습니다.
