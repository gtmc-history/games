## 사용 및 검수

단일 HTML 파일을 다운로드한 뒤 Chrome이나 Chromebook 브라우저에서 열어 시험합니다. 코드 읽기와 실제 브라우저 테스트는 별개의 검증입니다. 외부 역사 자료 링크 열람에는 인터넷이 필요하지만 게임의 기본 화면과 상호작용은 외부 라이브러리 없이 동작하도록 설계했습니다.

게임은 1972년 유신체제, 1975년 긴급조치 제9호, 1979년 부마민주항쟁을 대상으로 최초 판단 → 자료 확인 → 최종 판단·근거 작성 → TXT 내보내기를 수행합니다. **교사용 해설과 자료 카드는 학습용 재구성 문장으로 실제 당시 기사 원문이 아닙니다.**

## 검토 대기 중인 중요 쟁점

1. **부마민주항쟁 기사:** '중요한 내용 빠짐'뿐 아니라 '사실과 다름'으로 읽힐 여지가 있는지 실제 문장 기준으로 판단
2. **판단 보류:** 정답이 되지 않아 자료 부족 시 보류하는 역사적 태도를 가르치지 못하는 문제
3. **소거법:** 세 미션의 정답이 다름/일치/빠짐으로 한 번씩 등장하는 문제
4. **판단 변경 기록:** 첫 판단을 바꾼 이유를 묻는 별도 필드가 필요한지
5. **근거 품질:** 12글자 이상 입력은 내용 타당성을 증명하지 않음
6. **실행 검증:** Claude는 최초 노션 HTML 파일에 접근하지 못해 코드 검사·브라우저 실행을 하지 못했음. GitHub 링크에서 재검증 필요

## 역할과 변경 정책

- **GPT:** 기획·원본 HTML 및 통합 수정안
- **Claude:** 역사 사실 검증, 선택지 판정의 유일성, 코드 정적 검토
- **피클:** 고1 학생 관점 UX, 실제 화면·단말 사용성 검수
- **교사:** 최종 승인

검토 결과는 노션의 **자기 담당 영역**에 작성합니다. 원본 확인 여부와 테스트 범위를 반드시 명시합니다. 검수 브랜치에서만 고치고, 교사 승인 전에는 `main`에 병합하지 않습니다. 다른 AI가 GitHub 쓰기 권한이 없다면 수정 제안이나 전체 수정 파일을 노션에 남기되, GitHub에 업로드했다고 주장하지 않습니다.

학생 성명·학번 등 개인정보는 코드와 검수 기록에 올리지 않습니다.
