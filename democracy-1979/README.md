## v0.6 변경 사항

1. **1972/1975/1979 연도 도입 1컷씩**: WebP AI 생성 이미지, '연출된 학습용 이미지' 명시. 각 연도 첫 문항 직전에 한 번만 표시되며 '계속' 또는 '건너뛰기'로 넘어감.
2. **인라인 SVG 3종**: 1972 국민→통일주체국민회의 대의원→대통령 간접선출, 1975 유신헌법 제53조→긴급조치 제9호(비판·개헌 주장 금지, 영장 없는 체포·구금, 관련 보도 금지), 1979 부산(10/16)→마산·창원(10/18)→위수령(10/20). SVG는 각 연도 **첫 판단 후** 자료 화면에서만 보임. 역사 사진·원문 사료가 아니라 학습용 개념 도식이며, 지도는 축척을 보장하지 않음.
3. **짝수 문항 2·4·6의 자료 재봉인 제거**: 이미 확인한 A/B/C를 펼쳐 둔 채 **후속 최종 판단과 근거**만 작성한다. 최초 판단을 다시 수집하지 않으며 `initialMode=afterEvidence`, `sourceExposure=reused`, `initial=null`로 기록한다.
4. **홀수 문항 1·3·5만 독립 첫 판단**: 최초 자료 비노출 상태의 판단을 남기고, 이후 근거·판단 변경 이유를 작성한다. 판단 수정·보류 해제 통계의 분모는 **최대 3문항**이다.
5. **1975 자료 재구성**: 카드 A는 국사편찬위원회 「사료로 본 한국사」 긴급조치 제9호 원문 설명에 연결, 카드 B는 당시 표현·문화 통제, 카드 C는 2013년 3월 21일 헌법재판소 위헌 결정으로 교체. 원문 보도·조문·위헌 판단의 시점을 구분한다.
6. **기타**: `favicon` data 링크, 상태별 저장 키 분리(`history-1979-v06-draft`), 손상된 임시 저장 유효성 점검, 사전/후속 측정 구분 TXT, 후속 문항 포커스 이동, 44px 이상 근거 선택 버튼.

## 테스트(자체) 및 검수 범위

- 자바스크립트 `node --check` 통과, 6문항 자동 클릭 완주와 자료 노출·SVG 3종·기록 분모 구분·TXT UTF-8 BOM과 한국 시간을 확인함.
- **주의**: 테스트 환경에서 `file://` 경로 탐색이 차단되어 Chromium에 실제 HTML 소스코드를 직접 주입(`set_content`)하여 검증함. 저장·복원은 **모의 localStorage**로 확인. 학교 크롬북 실기기, native localStorage, GitHub Pages/학교망 링크는 재검증이 필요함.
- 교육 자료의 1975 긴급조치·2013년 위헌 판정 자료: [국사편찬위원회 원문과 설명](https://contents.history.go.kr/front/hm/view.do?levelId=hm_150_0100&treeId=020108) / [헌법재판소 결정](https://www.ccourt.go.kr/site/kor/ex/bbs/View.do?bcIdx=941627&cbIdx=1106).
