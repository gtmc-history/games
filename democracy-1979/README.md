## 바뀐 점

1. 1972·1975·1979의 각각 두 주장, **총 6개 판단**으로 확장. 권장 판정은 ‘일치’가 여러 번 등장하고 ‘사실과 다름’·‘중요한 내용 빠짐’·‘판단 보류’도 등장.
2. 공통 ‘사건 전체 설명’ 안내를 없애고 **주장별 판단 질문**으로 교체.
3. 1979년 항쟁의 생략 판정은 ‘1979년 10월 16일 부산대 학생 시위 시작’이라는 **참인 문장**을, **항쟁 전체를 설명하는 유일한 요약**으로 쓸 때 무엇이 부족한지 평가하도록 구성. 정답을 암시하던 ‘누가 빠졌는가?’ 제목 제거.
4. **1975년 당시 국민 70% 반대**라는 가상 수치 주장은 근거 카드에 여론조사 자료가 없어 **판단 보류**가 권장 판정. 70%는 역사적 통계로 확인된 수치가 아니라 **교육용 검증 대상 문장**입니다.
5. 최초 보류 → 최종 판단을 **‘보류 후 판단’**, 최초 확신 → 다른 판단을 **‘판단 수정’**으로 분리하여 집계.
6. 첫 판단과 최종 판단이 달라질 때 **변화·보류 해제 이유** 입력 요구. TXT에도 별도로 기록.
7. **기기 내부 임시 저장(localStorage)**, 이어하기, 기록 삭제 전 화면 내 확인, 한글 TXT 저장(UTF-8 BOM) 추가.
8. 출처 링크를 클릭 가능한 **별도 앵커**로 변경하여 키보드 접근성 개선.
9. 점수와 피드백은 **권장 선택지 분류**일 뿐 학생 서술 근거의 타당성을 자동 검증하지 않음.

## 검증 범위

- GPT가 Chromium 자동화로 **6개 과제 완주**, 최초/최종 판단 기록, 변화 이유, 결과 화면, TXT 다운로드·한글 인코딩을 확인했습니다.
- 320/390/768/1280px 화면의 가로 넘침 없음, 브라우저 콘솔 오류 0개를 확인했습니다.
- 이 환경의 웹 보안 제한으로 로컬 HTML 주소에 직접 진입하지 못하여, 동일 HTML 코드를 브라우저에 로드하고 **모의 localStorage**를 이용해 저장/복구 흐름을 테스트했습니다. **실제 학교 크롬북에서의 브라우저 저장·복구, 노션 임베드 및 GitHub Pages 배포는 별도 확인이 필요합니다.**
- 이 버전에는 **서버, 로그인, 자동 채점 API 또는 학생 개인정보 수집이 없습니다.** 외부 기록 출처 링크에는 인터넷이 필요합니다.

## 피클 검수 우선순위

- (1) 6개 문장이 고1 학생에게 **명확하게 판별되는지**
