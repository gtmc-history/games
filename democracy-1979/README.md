## v0.4 → v0.5 핵심 수정

1. **3장 확인 후 판단:** 이전 2/3장 열람에서 근거 없는 카드 조합 때문에 정당한 '판단 보류'가 오답 처리됐음. 이제 3장 모두 펼쳐야 **'최종 판단으로'** 버튼이 보이며, 학생이 직접 누른 뒤 다음 단계에 진입.
2. **중립적 질문:** 1975년 수치 주장·1979년 확산/생략 미션의 유도적 제목 수정, 제목 아래의 중복 질문을 '검토 주제'로 교체. 비어 있던 최종 질문 문구 작성.
3. **실제 근거만 기록:** '가장 결정적이었던 카드'는 학생이 실제 연 카드만 선택 가능. 제출 때도 방문한 근거에 속하는지 확인.
4. **70% 경고:** 1975년 '당시 국민 70% 반대'는 **미확인 가상 주장**이며 실제 통계가 아님을 **게임 피드백·종합 화면·TXT** 세 곳에 고지.
5. **한국 시간:** 기록 원본 시각은 ISO UTC로 내부 보존하되, TXT 기록 시간과 파일명은 `Asia/Seoul`로 표시, 초 단위까지 포함.
6. **접근성:** 카드 열기 직후 해당 버튼에 키보드 포커스를 복구. 기록 3장 모두 펼친 뒤 별도 진행 버튼으로 학생이 내용을 확인할 시간 보장.
7. **자료 출처 표기:** 카드 안에 '학습용 자료 요약 · 원문 직접 인용 아님' 표시. 1975년 유신시기 문화 표현 제약을 **긴급조치 제9호만의 직접 결과**로 단정하지 않도록 범위를 좁힘.
8. **표시:** 진행 막대는 진행 위치가 아니라 실제 완료한 판정 개수 기준. 입력 칸은 '현재 N자(최소 12자)'로 표시. 브라우저가 임시 저장을 차단하면 **시작 화면에서 경고**.
