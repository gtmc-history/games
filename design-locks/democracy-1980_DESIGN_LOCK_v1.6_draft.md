## §0 진단 — 왜 활동지처럼 보이는가

1. **설계 조항이 그렇게 정했다.** v1.2 §1 「Presentation: 짧은 비주얼 노벨풍 기록실(시각 25% 이내, 조작 75% 중심)」, §7 「Visual Novel 연출은 장면 분위기 전달만」. 구현은 이 조항을 그대로 따랐다.
2. **모든 장면이 같은 웹 양식 틀**(배너 → 지우 알림 줄 → 패널 띠 → 자료 목록 | 입력 양식)이고, 1366×768에서 장면 높이가 1,236~2,117px다. A·B의 실제 조작부(시간축 칸, 보기 버튼)가 첫 화면 아래에 있다.
3. **지우는 장면마다 한 번 말하고 끝난다.** 56px 초상과 [확인] 버튼, 학생 행동에 반응하지 않음.
4. **누적되는 결과물(전시 패널)이 플레이 중에 보이지 않는다.** 상단 띠의 회색 한 줄(잘림)과 S5 표 한 장뿐.
5. **결과 화면이 채점표처럼 보인다.** 「열람 없이 연결」「수정 이력: 없음」 꼬리표 — 교사용 데이터가 학생 화면에 노출.

## §1 Presentation (v1.2 §1 「시각 25% / 조작 75%」 조항 대체)

> **전시 벽이 게임판이다.** 학생의 모든 조작은 전시 패널이라는 물건 위에서 일어나고, 그 결과가 벽에 쌓인다. 지우는 무대 옆에서 학생의 행동에 반응하는 동료다.

- 비율 조항 「시각 25% 이내」는 삭제한다. 대신 **「텍스트 안내는 줄이고, 조작의 결과는 패널의 변화로 보여 준다」**로 바꾼다.
- 대사 분량은 늘리지 않는다(장면당 고정 대사 + 반응 대사 최대 3줄, 각 1회만).
- 학생 역할(2026년 기록 조사자)·지우 설정·1980년 인물 역할극 금지는 그대로.

## §7 화면·조작 (v1.2 §7 대체, 시안 A 기준)

| 영역 | 내용 |
| --- | --- |
| 한 화면 | 크롬북 1366×768·1280×720에서 **세로 스크롤 없이** 진행. 좁은 화면(≤980px)만 세로 흐름 + 하단 고정 손패 |
| 상단 바 | 전시 벽 미니맵 ①②③ — 완성한 패널이 켜진다(진행률 대체) |
| 전시 벽(주 무대) | 현재 패널 1장을 크게. 지우의 초안 문장 + 지도교사(가상) 메모가 패널에 붙어 있음. 조각을 놓을 칸·출처 꼬리표 자리·보류 상자가 패널 위에 있음. 아직 고치지 않은 패널은 벽 한쪽에 「초안」으로 걸려 있음 |
| 지우 자리 | 기존 장면 그림(01~06)을 지우 쪽으로 잘라 크게 + 하단 대화창(3표정 초상). 대화창은 스크롤로 사라지지 않음 |
| 손패(하단) | 사건 조각·보기 카드. 고르면 놓을 수 있는 칸이 빛남 → 칸을 누르면 붙음(드래그 강제 없음, 키보드 가능) |
| 조사 수첩(하단) | 출처를 **꼬리표**로 보관. [읽기]=안전 요약 시트(열람 기록), [꼬리표 들기]=바로 연결(열람 없이 연결 가능, v1.2 §11과 동일) |
| 판정 버튼 | 「패널 ① 복원」→ **「패널 ① 전시 벽에 걸기」**. 조건 미충족이면 비활성 + 「조각 n장 · 꼬리표 n개 더」 안내 |
| 실패 | 지도교사 메모가 **정본 힌트 문구**로 바뀌어 패널에 붙음 + 지우 반응. 정답 위치는 알려 주지 않음 |
| 성공 | 초안 문장에 취소선 → 복원 문장과 출처 꼬리표가 패널에 인쇄됨 → 「전시 가능」 도장 → 미니맵 ① 켜짐 |
| 움직임 | 카드 붙기·도장·메모 교체 정도. 타이머·효과음·흔들림 없음. reduced-motion이면 모두 끔 |
