## 1. GAME DESIGN LOCK

### Historical Discovery
> 1905년의 편입 조치는 그 이전의 기록(1877·1900·1904)과 그 이후의 기록(1906)을 함께 놓고 읽을 때 판단할 수 있으며, 각 사료는 말할 수 있는 범위가 서로 다르다.

### 두 층의 질문
- **사건 질문 (한국사 맥락)**: 1905년의 조치를 판단하려면 그 이전의 어떤 기록을 확인해야 할까?
- **반복 조사 질문 (사료 탐구 엔진)**: 1900년 칙령 제41호의 `石島`는 우리가 조사하는 이 섬을 가리키는가?

### 3행 설계 게이트
- **발견 한 문장**: 위 Historical Discovery
- **플레이 동사**: 찾는다 · 판단한다 · 배치한다
- **행동의 이유**: 전시 개막 전 "근거 검수 보류"가 걸린 패널을, 연구 인턴인 내가 사료로 검증해 확정해야 한다.

### Player Verb (이 셋만 허용)
1. **찾기** — 사료 원문(번역)에서 표현을 터치해 표시한다. 지도에서 섬·명칭을 짚는다.
2. **판단** — 석도 질문에 대한 현재 판단을 기록하고, 새 자료 뒤에 약화/그대로/강화로 갱신한다.
3. **배치** — 획득한 사료 카드·구절을 칸(분류함, 전시 패널)에 놓는다.

비주얼노벨 대화는 **장면 전환 연출**, 시간 띠는 **상시 정보 UI**이며 메커닉이 아니다.
관계선 긋기, 별도 문서 분해, 항해, 타일맵은 v2에서 사용하지 않는다.

### Core Sequence
`1905 결정문에서 의문 발견 → 이전 기록 역추적(1877·1900) → 판단 기록 → 새 기록(1904·1906)으로 판단 갱신 → 전시 패널 확정`

### Game Fit
- 사료의 범위·관계·시점을 학생이 직접 다뤄야 하는 주제다. 결론 요약 강의보다 "판단이 새 자료로 움직이는 경험"이 학습 목표와 직결된다.

### Engagement Hook
- 검수 보류된 전시 패널(해결해야 할 사건), 잠긴 파일이 차례로 열리는 구조, "5분 전의 나"와 새 자료가 나란히 놓이는 판단 갱신 순간.

### Primary / Secondary Mechanic
- Primary: Belief Updating (석도 판단 궤적)
- Secondary: Document-driven Investigation(찾기), Editorial Simulation(전시 배치)

### Presentation Layer
- 현대 연구소 분석 UI + 사료 레이어(문서 원문 번역·지도 도식). 상단 시간 띠 상시 표시.

### State Variables
- `found[]` 찾은 구절 ID / `cards[]` 획득 사료 카드
- `j1900` ∈ {low, unsure, possible}
- `u1904`, `u1906` ∈ {weaken, same, strengthen}
- `opened[]` S4 선택 열람 자료
- `sort1906{}` 1906 구절 분류 결과
- `panel.cards[3]`, `panel.claims{}`(카드별 표현 강도), `review` ∈ {add, narrow, keep}, `closing` 문장 ID

### Meaningful Choice
- 판단 정보: 각 장면에서 공개된 사료만.
- 선택 간 실질적 차이: 판단 궤적이 결과 화면·짝 비교에 그대로 남는다. 전시 문구 강도가 검토 의견을 부른다.
- 위장 객관식 여부: 석도 판단·갱신에는 정오 피드백이 없다(해석층). 사실 찾기에만 정오 피드백.

### Consequence
- 즉시: 찾기 정오 피드백, 카드 획득, 시간 띠 점등.
- 지연: S3 판단이 S4·S5에서 "이전의 나"로 다시 등장. S6 표현 강도가 검토 의견을 부름.
- 판단 변화: 결과 화면에 궤적 표시.

### Replayability
- 불필요. 1회 수업용. 재시작 가능.

### 기존 게임과 가장 가까운 구조 / 차이
- `geunal1945`(Belief Updating, Confidence), `newsroom1945`(편집) — 차이: 판단 대상이 "한 사료 표현의 지시 대상"으로 고정되어 게임 전체를 관통하고, 시간 띠로 국권 침탈 맥락이 상시 결합된다.

## 2. 역사적 불변 원칙

1. 1900 칙령 제41호 원문의 `石島`를 학생 화면에서 "독도"로 미리 치환하지 않는다.
2. 1877 기죽도약도는 1876년 시마네현 제출 자료가 같은 「공문록」 일건에 편철된 관계로 제시한다. "태정관 최종 지령에 직접 첨부된 지도"라고 단순화하지 않는다.
3. 1904 군함 니타카 기록은 일본 군함이 (울릉도에서) 청취해 기록한 자료다. 대한제국의 공식 명명 문서로 바꾸어 읽지 않는다.
4. 1904 군함 쓰시마 조사 등 군사·통신 맥락은 시대 배경이며, 1905년 편입의 단일·직접 원인으로 확정하지 않는다.
5. 1906 보고·지령에서 "본군 소속 독도"(울도군의 인식), 일본 측 통보, 중앙정부의 재조사 지시를 구분한다.
6. 1906 자료 하나가 1900 `石島`의 동일성을 자동 증명하는 것처럼 구현하지 않는다.
7. 1906 대응 설명은 "을사늑약 이후 대한제국의 대외 외교권이 크게 제약된 상황에서, 지방 보고가 중앙정부로 올라가고 중앙에서는 사실관계 재조사를 지시하였다"로 표현한다.

### 학생 행동이 바꿀 수 있는 것
- 자신의 판단 궤적, 전시 패널에 쓸 근거와 표현 강도.

### 바꾸면 안 되는 실제 역사
- 문서의 날짜·주체·내용, 1904~1906 사건 순서.

### 후견지명 차단
- 판단 #1(S3)은 1904·1906 자료 공개 전에 기록한다. S3에서는 1904·1906 카드가 잠겨 있다.

## 5. 민감 주제 체크

- 적용 대상: 예 (영토 문제, 국권 침탈)
- 학생의 Agency: Inquiry + Interpretive + Editorial
- 폭력·피해 재현: 없음
- 실존 인물: 심흥택·박제순·나카이는 **문서 작성·언급 주체**로만 등장. 대사·내면 창작 금지. 학생이 이들을 연기하지 않음.
- 일본 측: 사람 캐릭터로 등장시키지 않음. 문서(각의결정, 외무성 설명)로만.
- 구도: 법정·재판·ICJ 모의 구도 사용 금지. 학생 역할은 "검수·설명하는 연구 인턴".
- 혐오 방지: 결과·디브리핑이 상대에 대한 적대로 귀결되지 않도록 "근거로 설명하기"로 마무리.
- 가공 인물: 선임 연구원(현대 가공 인물) 1명 — 진행 안내만, 역사 판단 대행 금지.

## 7. UI / Presentation (v2.1 연구소 책상형)

- 시점: 현대 탐구자(연구 인턴).
- 화면 구조: 상단 진행 칩(검수·1905·1877·1900·1904·1906·전시) + 시간 띠(점과 선, 점등 시 설명 표시) / 왼쪽 **사료 책상**(문서·지도·카드·칸 — 모든 터치 조작은 여기) / 오른쪽 **작업판**(선임 연구원 말풍선, 과제 n/m, 맥락 노트, 판단 버튼, 판단계, 확보한 사료).
- 휴대폰(≤860px): 사료 책상 ↔ 작업판 탭 전환. 장면 진행에 따라 자동 전환하고 새 내용이 있는 탭에 점 표시. 사료 책상 위쪽에 현재 과제를 고정 표시.
- 장면 도입: 연도 파일철 오버레이(FILE 01~06)로 장면 전환 — 연출이며 메커닉 아님.
- 찾기 표시: 터치 가능한 구절은 형광펜 칩. 찾은 구절은 진한 형광 + ✓. 2회 오답 시 목표 구절이 깜박이는 힌트.
- **석도 판단계**: 판단 궤적을 7칸 눈금 위의 점으로 표시. 1900 판단(낮다/어렵다/있다 → 2/4/6칸), 1904·1906 갱신(덜 그렇다 −1 / 그대로 0 / 더 그렇다 +1). 지난 판단은 회색 점, 고르는 중인 판단은 파란 점. 눈금 양끝은 "다른 섬일 것 / 이 섬일 것", 정답 위치 없음.
- 판단 갱신 버튼 문구: "← 덜 그렇다 / 그대로다 / 더 그렇다 →" — 기준은 항상 "石島는 이 섬이다"라는 생각(저장 값 weaken/same/strengthen 유지).
- 전시 단계: 실제 전시 패널 모양 위의 빈칸에 카드 배치 → 칸마다 차례로 문장 선택(빨간 테두리 칸) → 검토 의견 → 패널 맨 아래 맺음 문장.
- 터치 48px 이상, 본문 16px 이상, hover 전용 기능 없음. 드래그 없음(탭 2회).

## 8. 학습지 / API 의존성

- Worksheet: 기본 플레이에 불필요. 지도안의 활동지는 결과 화면을 옮겨 적고 짝 비교하는 용도.
- External API: 저장(Supabase game_results)은 보조. 실패해도 결과 화면 표시.
- 로그인 없음. 다른 학교 교사가 링크만으로 사용 가능. `?class=` 선택 파라미터.

## 9. 결과 화면

- 선택 궤적: 1900 → 1904 → 1906 판단 궤적.
- 결과물: 전시 패널(근거 3장·표현·맺음 문장).
- 남은 불확실성: 사료별 "이 자료만으로 확인하기 어려운 것".
- 점수: 사용하지 않음.

## 10. 게임 후 발문

> 같은 사료를 사용하더라도 '사료가 직접 말하는 것', '여러 자료를 연결해 해석한 것', '오늘날 우리가 평가하는 것'은 어떻게 달라지는가? 네 전시 패널에서 이 세 층을 하나씩 찾아보자.
> 짝과 판단 궤적을 비교해 보자. 너의 판단은 어느 자료에서 움직였고, 왜 그랬는가?

## 12. 구현 금지 / 변경 금지

- 석도 판단에 정답·점수·확신도 상승 경로 강제 금지.
- 石島를 화면에서 독도로 치환 금지.
- 일본 측 인물 캐릭터, 재판 구도 금지.
- 사료 원본 이미지는 이용 허락 전 사용 금지.
- 메커닉 추가 금지(찾기·판단·배치 외).
