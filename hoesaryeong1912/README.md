## 1. 핵심 발견 문장 (v1.4 교체 잠금)

> **회사를 세우려면 총독의 허가가 필요했고, 허가 뒤에도 일정 기간 내에 회사를 성립시켜야 했으며, 성립한 뒤에도 총독부의 정지·해산 권한 아래 놓였다.**

- 학생 언어 버전(디브리핑용): *"허가를 받으면 끝인 줄 알았는데, 왜 회사가 된 뒤에도 총독부의 권한이 계속될까?"*
- 근거: 제1조 허가(A1) · 제4조 1년 내 성립 의무(A8) · 제5조 조건·정지·해산(A2) — 전부 법문(A급). (제6조 부실 신고 취소는 A 원장 미등재이므로 발견 문장 근거에서 제외 — 새 발견에 필수적이지 않음)
- **v1.3 이전 발견 문장("신청자는 자기 계획을 스스로 바꾸어 갔다")은 폐기** — 계획 변경·보완·재신청이 일반적 절차였다는 근거를 확보하지 못함 (D4 실패, 기각 이력 참조). 단, "회사령에 '조선인은 회사를 세울 수 없다'는 조항이 없었다"는 사실 자체는 유효(A급)하므로 **디브리핑 자료로 이동** — 조항 없는 법과 차별적 운용(B2·B4·B9)의 대조는 여전히 이 게임의 학습 재료다.
- 이 문장이 게임의 종료 조건을 정의한다: 학생이 '허가 = 종착점'이라는 통념이 깨지는 순간, 그리고 자신의 R3 결정(성립/비회사)을 감독 구조와 대조하는 순간 학습 목표가 달성된 것으로 본다. '승리 조건' 프레임 사용하지 않음.

| C4 | **R3 ② '비회사 유지'는 역사적으로 가능한 합성 경로**: 제4조에 따라 허가 후 회사를 성립시키지 않으면 허가가 실효될 수 있었고(A8), 동시에 공소·염직소 등의 비회사 사업 형태도 실제 존재했다(B12). 다만 **'허가를 받은 뒤 의도적으로 비회사 형태를 선택한 동일 사례'는 확인되지 않았다** — 법문 + 실례의 결합이지 연속된 실증 사례가 아님 | C등급 정직 표기. 동일 사례 발견 시 B로 격상 |

### 기각 이력 (재발 방지)

| 기각된 설계 | 기각 사유 |
|---|---|
| "일본인과 합자하면 허가가 쉬워진다"를 핵심 규칙으로 사용 | **일본인과 합자하면 허가가 쉬워진다는 직접 사료가 확인되지 않았으며, 민족별·합자 회사 구성비 통계만으로 허가상의 우대를 추론할 수 없다.** (합자 구성비 감소 통계 역시 반대 방향의 인과 추론 근거로 쓰지 않는다 — 결과 통계로 허가 과정의 인과를 양방향 모두 역추론 금지) |
| "허가 가능성 N%" 확률 표시 UI | B1은 전 기간·전체 신청의 집계이지 특정 시점 특정 신청자의 확률이 아님. 집계치의 개인 확률 전용 금지 |
| "지주 경영으로 회귀" 선택지 | 가공 인물의 삶을 작가가 과도하게 조작. "회사 설립을 접고 기존 상업을 유지"로 대체 |
| 허가 획득 자체를 게임 목표로 설정 | 총독부의 정답 맞히기 게임이 됨. 목표는 "나는 무엇을 바꿀 것인가"의 궤적 |
| R2 신청 대응 선택지 (`apply_stance`: 그대로 신청 / 손보고 신청 / 보류) | '손보고 신청'은 R3의 계획 변형과 중복되며, 심사 결과를 받기 전에 계획을 고치는 것은 "총독부가 좋아할 답을 미리 맞혀라"로의 회귀. '보류'는 전원 R3 도달 구조와 충돌 (보류한 학생의 선택을 게임이 무효화해야 함). R2는 발견·정보 씬으로 확정 |
| R1 선택에 따라 R3 조건의 무게가 달라지는 설계 | R1 선택이 심사 강도·허가 가능성·조건의 무게를 결정하면 숨은 인과 규칙이 재생성됨 (예: 조선인 자본만 → 무거운 조건 = 폐기한 '합자 우대'의 변형판). **R1 선택은 총독부를 움직이는 입력값이 아니라 학생 자신이 나중에 돌아볼 '원안'이다** |
| **불허의 플레이 경로** (일부 학생에게 불허 배정) | 2026.8.22 기각. ① 불허된 학생은 핵심 씬 S4(허가 이후의 통제)를 경험하지 못하고 게임이 "허가받기 게임"으로 회귀 ② 불허 여부를 R1 선택과 연결할 인과 근거 없음, 무작위 배정은 학생이 원인을 찾는데 게임이 답을 줄 수 없음 ③ "불허를 많이 하는 제도" 프레임으로 후퇴 — 게임의 진전(사전 판단+사후 감독의 통제 구조)을 약화. **대체: S5 '가지 않은 길' 방식** — 불허의 실재(B9·B10)를 자료로 제시 + 비적용 고지 (SCENE_TEXT v1.4) |
| R1 업종 선택 변수 (`sector`) | 업종별 심사 차이를 구현하려면 근거 없는 업종→심사 인과 규칙이 필요하고, 차이가 없다면 선택은 장식임. 결정적으로 업종은 R3의 변형 대상이 아니어서(총독부가 정미를 직뉴로 바꾸라고 요구하지 않음) 결과 패턴에 하중이 없음. 선택의 하중은 "무슨 사업을 할 것인가"가 아니라 **"이미 하던 사업을 '회사'로 만들기 위해 무엇을 바꿀 것인가"**에 몰아준다. 업종은 직뉴·섬유 제조로 고정 (C1). 정미는 비교 사례로 보관, 물산·무역(백산상회 계열)은 시기·지역·목적 불일치로 제외 |
| R1 동업 구성 변수 (`capital_mix`: 조선인 동업자만 / 외부 자본 유치) | 한일 합동회사의 존재는 사실이나, **1912년 광희문 직뉴업자가 일본인 자본 유치를 현실적 선택지로 가졌다는 근거 미확보**이며 선택 결과의 심사 유불리는 더더욱 근거 없음. 학생은 선택지의 존재 자체에서 의미를 읽으므로 — 효과가 없으면 장식, 효과를 주면 창작된 인과. 삭제. 근거가 발견되면 재상정 가능 |
| **구 R3 가설: 조건 통지 → 계획 변경 → 재신청 구조** (v1.0~v1.3) | **D4 실패 종결(2026.8.21)로 폐기.** 웹 공개 자료·공개 DB에서 1911~1913년의 허가 조건·계획 변경 요구·보완 후 재신청·조건부 인가 문서를 하나도 확보하지 못함. 조건부 허가의 법적 존재(제5조 "허가의 조건" 문언)만으로는 '통지 받고 고쳐서 다시 낸다'는 **절차**를 지탱할 수 없음 — 절차의 창작은 결과 자료의 절차 전용 금지 원칙과 동일하게 금지. 이 폐기와 함께 구 발견 문장의 "계획을 스스로 바꾸어 갔다"도 폐기. **향후 독서 중 관련 사례가 발견되면 사료 원장 보강 사항일 뿐, 게임 구조의 재변경 사유로 자동 승격하지 않는다** |

**일반 원칙 (전 게임 재사용, 이 게임에서 확립):**

> **결과의 분포는 제시할 수 있지만, 그 결과만으로 선택→결과의 숨은 인과 규칙을 만들지 않는다.**

통계형 자료를 게임 규칙으로 전환할 때의 상위 기준. "숨겨진 규칙은 역사 사료로 근거해야 함" 원칙의 통계 특화 버전.

## 3. R1~R3 결정 변수 표

> 형식: **역사적 조건 → 학생 결정 → 이후 남는 흔적(choices 기록)**.

### R1 — 설립 계획 (제도 개입 이전의 '내 계획') — v1.5 확정

> **"왜 회사인가" (잠금):** *회사는 여러 사람이 자본을 모아, 개인이나 소규모 업자가 혼자서는 하기 어려운 규모의 사업을 조직할 수 있는 **한 가지 방식**이었다.* (근거: B11 — 광희문 가내공업자들의 합명→주식 경로, B13 — 설립 붐·발기인 요건. "회사여야만 가능했다"는 반사실 주장 아님)
>
> 업종은 고정 설정 (직뉴·섬유 제조 — C1, B11). `capital_mix`·`scale_initial`은 폐기 (기각 이력·부록 D).

| 변수 | 역사적 조건 | 학생 결정 | 흔적 (choices) | 근거 |
|---|---|---|---|---|
| 회사 형태 | 합명·주식은 당대에 실재한 법적 회사 형태이며, 경성직뉴가 합명(1910)→주식(1911.6) 양쪽을 실제로 밟음 | ① **몇 사람의 동업자가 함께 책임지는 합명회사 형태로 세운다** ② **주식을 나누어 출자자를 모으는 주식회사 형태로 세운다** | `company_form` (`hapmyeong` / `jusik`) | B11, B13 |

- 4장 카드 설명(잠금): **합명회사** — 몇 사람의 동업자를 중심으로 회사를 꾸린다. / **주식회사** — 자본을 주식으로 나누어 여러 출자자가 참여할 수 있게 한다.
- 무한책임/유한책임은 툴팁 후보로만 유보 — R3 결정에 실제로 쓰이지 않으면 전면에 올리지 않음.
- **금지: "합명=작은 회사, 주식=큰 회사"라는 고정 규칙 생성 금지** (부록 D). 결과 패턴은 규모 축이 아니라 선택 궤적으로만 분류.

- R1에서는 회사령의 차별적 운용을 전면에 보여주지 않는다. 학생은 '사업 계획'을 세우고 있다고 느껴야 한다.

### R2 — 허가 신청과 심사 (발견 씬 — 학생 선택 없음, 확정)

> **게임 리듬: R1 결정 → R2 발견 → R3 결정.** 모든 씬에 선택지가 있어야 게임인 것은 아니다. R1에서 자기 계획(원안)을 충분히 만들었으므로 R2가 정보·긴장 씬이어도 행위자성은 유지된다.

| 요소 | 내용 | 근거 |
|---|---|---|
| 발견 내용 | 제출한 사업계획이 자본·수익성뿐 아니라 **신용·이력·정치적 성향까지** 조사 대상이 된다는 것 | A1, B2 |
| 대비 자료 | 일본 상법의 자유설립주의(B8) — "일본에서는 등기만 하면 되는 일이, 여기서는 왜 허가인가"라는 질문의 씨앗 | B8 |
| 기록 | 없음 (`apply_stance` 삭제 — 기각 이력 참조) | — |

### R3 — 허가 수령 → 성립 결정 (v1.4 재설계, 잠금)

> **[구조] 허가가 나온다 → 학생은 1년 안에 회사를 실제로 성립시킬 것인가를 결정한다.**
> **[전원 허가 원칙 — D3 계승]** 모든 학생에게 허가가 나온다. 이것은 게임이 선택한 **하나의 역사적으로 가능한 상황**이다 (경성직뉴가 1911년 실제로 허가받음 — B11). 플레이어의 R1 선택과 허가 사이에 어떤 숨은 인과도 두지 않는다 (통계 사용 원칙·기각 이력과 정합).

| 변수 | 역사적 조건 | 학생 결정 | 흔적 (choices) | 근거 |
|---|---|---|---|---|
| 허가 수령 | 허가는 종착점이 아니다: 1년 내 성립 의무(제4조), 허가 조건과 존속 중 정지·금지·폐쇄·해산 권한(제5조) | — (수령·발견 장면) | `permit_received` (시스템 기록) | A1, A2, A8, 부록 C |
| 성립 결정 | ①은 실증 사례 존재(경성직뉴 등), ②는 **역사적으로 가능한 합성 경로(C4)** | ① **회사를 성립시킨다** — 회사라는 법적 지위를 얻지만, 동시에 회사령의 감독·정지·해산 권한 아래 들어간다 ② **성립시키지 않고 기존 공소·사업 형태로 남는다** — 허가는 효력을 잃고(제4조) 회사 명칭·지위는 취할 수 없지만(제12~14조) 사업 자체는 계속한다 | `final_decision` (`incorporate` / `stay_noncompany`) | ① A2·A8·B11 ② **C4** (법문 A8 + 실례 B12의 결합 — 동일 사례 미확인 정직 표기) |

- **잠금 등급: R3 구조·대가·이득 표현 모두 확정 (v1.5).** ①의 이득은 "왜 회사인가" 잠금 문장(R1 절)으로 지탱: 여러 사람의 자본을 모아 더 큰 사업을 조직하는 방식이라는 것. ②의 유지·포기는 C4·B12·처벌 조항으로 지탱.
- **R1은 R3의 결과를 발생시키지 않지만, 학생이 자기 결정을 해석하는 맥락은 달라진다** — 주식형 원안: "출자자를 모아 조직된 회사를 구상했는데, 성립 이후에도 감독권 아래 놓인다" / 합명형 원안: "몇 사람과 만들려 했지만, '회사'가 되는 순간 같은 허가·감독 구조 안으로 들어간다". 이것은 숨은 인과가 아니라 궤적의 의미 차이다.

- 두 경로에 우열 없음. ②는 도피가 아니라 법적 경계선 안의 실제 경제적 선택 (B12).
- 정오 피드백 사용 안 함 (판단형 — SKILL v2.1 §2-3). 선택 후에는 각 경로의 조건·대가만 제시.
- 결정의 이유 장치 → **4장 v1.0에서 `decision_reason`으로 확정** (문구·validation 잠금).

### 결과 패턴 (점수 대신 패턴 — v1.5 확정)

**`company_form` × `final_decision`의 4궤적**: 합명 구상×회사 성립 / 합명 구상×비회사 유지 / 주식 구상×회사 성립 / 주식 구상×비회사 유지. 규모 축(`small/large`) 분류 금지 — 궤적일 뿐 우열·크기 서열 없음. 결과 화면은 "당신은 어떤 형태의 회사를 그렸고, 허가장을 받아든 뒤 무엇을 결정했는가 — 그 결정으로 어떤 권한 아래 놓였는가 / 무엇을 취하지 않았는가"를 시각화. 유형의 학생용 명칭과 반 통계 표시(소수 응답 보호 포함)는 4장에서 확정.

### 뒤집기·F형 (개요만 — 4장에서 상세화)

- 뒤집기: B1(82.2% 집계) + B3(회사 수 변화) + A5(납입자본 비율) + B9(조선인 신청 처리 내역)를 **사실의 층으로만** 제시. 원인 해석은 학생. 회수 목표: *"내가 허가받았다는 사실이 회사령이 느슨했다는 뜻도 아니고, 특정 선택이 허가를 보장했다는 뜻도 아니었다."*

### 4-2. `decision_reason` — R3를 두껍게 하는 장치 (문구 잠금)

R3 결정 직후 "가장 큰 이유 하나"를 고르게 한다. **학생 자신의 판단 이유**이지 역사 주장이 아님. 확정 문구:

**회사 성립 시 (2택)**
- `partners` — **함께 회사를 준비한 사람들과의 약속을 지키고 싶어서** (⚠️ 사용 조건: 5장 R1에서 동업자·출자자의 흔적을 계획서에 실제로 남긴 뒤에만 성립 — 5장 요건 §5-2)
- `expansion` — **여러 사람의 자본을 모아 사업을 넓히고 싶어서** (B11 구조와 직결, "왜 회사인가" 잠금 문장 수위 준수)

**비회사 유지 시 (2택)**
- `oversight` — **회사가 된 뒤에도 이어지는 감독·정지·해산 권한이 부담되어서** (A2·A8)
- `keep_way` — **지금 방식으로 사업을 계속하는 편이 낫다고 생각해서** ('충분히' 배제 — 게임이 가공 인물의 사업 전망을 대신 판정하지 않음. 순수하게 학생의 판단)

**저장 validation (잠금):** `incorporate → partners | expansion`만 허용, `stay_noncompany → oversight | keep_way`만 허용. 잘못된 조합은 저장 단계에서 차단.

**v2 검토 메모:** "다른 이유가 있다" + 30~50자 입력 옵션은 v1에서 도입하지 않음 (수업 시간·대시보드 단순성 우선). 2택이 학생 사고를 제한하는 약점은 인지하되, 수업 발문에서 열린 질문으로 보완.

### 4-3. 수업 발문 (v1.0 교체 잠금 — C4 경계 준수)

1단계: **"우리 반은 같은 허가장을 받고도 서로 다른 결정을 했다. 게임 속 인물이 고려한 조건 가운데, 당시의 법령과 실제 사례로 확인할 수 있는 것은 무엇일까?"**
2단계: **"그 근거만으로 실제 업자들도 우리와 같은 이유로 결정했다고 말할 수 있을까?"**

— 사실↔합성↔해석의 경계가 수업 자체로 회수되는 구조. (구 발문 "실제 업자에게 이 결정을 망설이게 했을 조건"은 C4가 피해 온 '실제 업자가 이 결정을 고민했다'는 전제를 재도입하므로 폐기.) 4궤적 분포 + 결정별 이유 분포를 화면에 놓고 진행, F형(3장 잠금)으로 연결.

### 4-4. 대시보드 집계 (game_meta 등록 항목)

- 차트 1: 4궤적 분포 (2×2 매트릭스 렌더러 검토)
- 차트 2: **결정별 조건부 이유 분포** — 회사 성립 학생 안에서 `partners`/`expansion` 비율, 비회사 유지 학생 안에서 `oversight`/`keep_way` 비율을 **분리 표시**. ⚠️ 네 값을 한 차트에 합산 금지 — 서로 다른 모집단(제시된 선택지가 다름)의 직접 비교가 되기 때문
- 소수 응답 보호: n 미만 비율 미표시 (원칙 ⑧) — 조건부 분포에서는 분모가 작아지므로 특히 중요

## 5장 — 6씬 상세 (v1.0 잠금 — 2026.8.22 검수 5건 반영)

> **5장의 중심 과제 (검수 지침 계승):** R1에서 만든 계획서가 R3에서 실제로 다시 눈앞에 돌아와, 학생이 "내 계획을 버릴지 말지"를 **느끼게** 만드는가. 이를 위해 **'계획서'를 전 씬 관통 오브젝트**로 설계한다 — S1에서 펼쳐지고, S2에서 학생 손으로 채워지고, S4에서 허가장 옆에 다시 놓인다.

### §5-1. S1 도입 — 1912년, 광희문 밖 (1~2분)
- 주제 고지 1줄 (원칙 ⑧): "이 게임은 일제강점기 경제 통제 제도를 다룹니다." (18자 ✓)
- 주인공 소개 (C1): 광희문 일대에서 직뉴(끈목)를 짜서 파는 업자. 몇 해 모은 밑천과 거래처. 이웃 업자들과 회사 설립 이야기가 오감 (B13의 설립 붐 분위기).
- 화면: 빈 **계획서** 펼쳐짐. 근현대 팔레트(세피아·낡은 종이 텍스처, SKILL §1).
- 텍스트 초안(도입 카드, 80자 제한): "광희문 밖에서 몇 해째 직뉴를 짜 팔고 있다. 이웃 업자들과 회사를 세우자는 이야기가 오간다. 계획서를 펼친다." (57자 ✓ — '여덟 해'는 불필요한 가짜 정밀도로 제거)

### §5-2. S2 R1 — 계획서를 쓰다 (2~3분) `company_form` 기록
- 선택 카드 2장 (3장 잠금 문구 + 4장 카드 설명).
- **선택 흔적 연출 (확정 — partners 사용 조건 양쪽 충족):** 합명 선택 → 계획서에 "동업자: ○○, ○○ …" 이름 줄이 적힘 / 주식 선택 → 계획서에 **"발기인: ○○, ○○ … / 주식을 나누어 출자자를 모은다"**가 적힘 (발기인 신고 요건 B13 근거. 실제 인명·인원 수 특정하지 않음). **"2,000주" 수치는 사용 금지** — 경성직뉴 고유 수치의 재현(원칙 ⑥)이자 당대 일반 규모로 오인될 위험, 부록 D 일반화 금지와 일치.
- 판단형 선택 — 정오 색상 금지 (SKILL §2-3), 기록 후 씬 전환만.

### §5-3. S3 R2 — 신청, 그리고 발견 (3~4분) 선택 없음
- 순차 공개: ① 허가제 조문 카드(A1, 교과서 자료2 원문) ② 서류 요구 — 발기인 전원의 이름·주소·보유 주식·보수 신고(B13) ③ 심사 범위 — 재력·신용·수익 전망, 그리고 **이력과 성향까지**(B2) ④ 대비 카드 — "일본 본국: 등기하면 회사가 된다"(B8) ⑤ 총독부의 자기 논리 — 조선인 보호론(B13).
- 긴장 연출: 정보 통제형이 아닌 **서류·심사의 무게** 연출 — 도장·검열 스탬프 남발 금지, 문서가 쌓이는 물리 연출 (SKILL §5 행정·결재형 준용).

### §5-4. S4 R3 — 허가장과 계획서 (4~5분) `final_decision`·`decision_reason` 기록
- 비트 1: **허가장 도착.** 표시 내용은 **"허가 결과: 회사 설립 허가"만** — 조건 조항의 존재를 허가장 위에 표시하지 않는다 (개별 통지의 조건 기재는 미확보 사료, C2 잠금. 학생이 느껴야 하는 것은 "내 허가장에 조건이 적혔다"가 아니라 **"허가를 받았어도 이 법은 계속 적용된다"**).
- 비트 2: **별도의 법령 카드 2장 — 허가장과 시각적으로 분리.** 제4조(A8)·제5조(A2, 교과서 자료2와 동일 조문). R3 선택지가 나타나기 전에 두 법령이 화면에 자동 노출·확인되는 방식 (클릭 의식 강제 아님). 핵심 증거는 잠그지 않는다.
- 비트 3: **계획서 회귀.** 허가장 옆에 S2에서 학생이 채운 계획서가 다시 놓인다 — 합명이면 동업자 이름들, 주식이면 출자 모집 계획이 그대로 보임.
- 비트 4: 성립 결정 2택 (3장 잠금 문구) → `decision_reason` 2택 (4장 잠금 문구, validation 적용).
- 판단형 — 정오 연출 금지. 결정 후 각 경로의 조건·대가 카드 1장 (3장 R3 표 문구 기반, 120자 제한 검수는 코드 단계).

### §5-5. S5 뒤집기 — 회사령 아래의 숫자들 (2~3분) 선택 없음
- 제목 확정: **"회사령 아래의 숫자들"** ("그해의 숫자들"은 부정확 — B1은 기간 전체 집계, B3은 1911→1919, A5는 1911→1917).
- **중심 3단계: B1(82.2% 집계) → B9(조선인 신청 43건 처리 내역) → A5(납입자본 17.0%→12.7%, 교과서 정본).** B3(회사 수 변화)는 보조/펼치기 자료로 강등 — 뒤집기의 목적은 통계 폭격이 아니라 "나는 허가받았다 → 그런데 전체 그림은 단순하지 않다"의 한 번의 반전.
- 회수 문장 표시 (3장 뒤집기 절): "내가 허가받았다는 사실이 회사령이 느슨했다는 뜻도, 특정 선택이 허가를 보장했다는 뜻도 아니었다."
- ⚠️ 확률·개인화 환산 금지 (기각 이력) — 숫자는 집계로만, 학생 궤적과의 인과 연결 문구 금지.

### §5-6. S6 결과 — 당신의 궤적 (2~3분)
- 4궤적 패턴 표시 (4장 규격) + **서술형 궤적 명칭 (§5-7 확정: `합명 구상 → 회사 성립` / `합명 구상 → 지금 방식 유지` / `주식 구상 → 회사 성립` / `주식 구상 → 지금 방식 유지`)** + F형 발문(3장 잠금) 화면 표시.
- 반 통계 버튼 `[우리 반 지금까지 선택 보기 →]` (아이디어 1.5 방식, 소수 응답 보호).
- 소감 입력(선택, 표준 속성) + 복사 버튼 + 저작권 푸터.

### §5-7. 미정 사항 — 전부 종결 (2026.8.22 검수)
1. ~~S2 "2,000주"~~ → **삭제 확정** (§5-2 반영).
2. ~~궤적의 학생용 명칭~~ → **별명을 붙이지 않는다. 서술형 확정: `합명 구상 → 회사 성립` / `합명 구상 → 지금 방식 유지` / `주식 구상 → 회사 성립` / `주식 구상 → 지금 방식 유지`** — 게임이 실제로 기록한 두 선택만 말함. (가안 "동업은 계속, 회사는 없이"는 동업관계 지속을 새로 주장, "모집을 접다"는 모집 진행·중단을 함의하므로 기각)

### §5-8. 잠금 리듬 (요약)
**빈 계획서 → 내 회사 형태를 적음 → 허가를 받기 위해 나에 대한 조사까지 이루어짐 → 허가장 도착 → 제4·5조 확인 → 내 계획서가 다시 돌아옴 → 성립 여부 결정 → 이유 기록 → 전체 통계로 내 경험 뒤집기 → F형 판단.**

### 6-2. 데이터 계약 (지침 v3 신규 표준 전항 적용)
