## 0. 핵심 문장

> **이 게임에서 학생의 선택은 '미래를 맞히는 것'이 아니라, 어떤 증거를 더 요구할지 결정하고 그 증거에 따라 자신의 판단을 수정하는 것이다.**

- 게임 유형: **역사가(탐구자) 게임** (v2 불확실성 분류 — 안상호와 같은 축)
- 학생의 위치는 처음부터 끝까지 "발표문과 자료를 검토하는 탐구자". 특정 연도의 당대인으로 라벨링하지 않는다. 시간 라벨은 **증거에만** 붙인다.
- 예측 정확도는 점수화하지 않는다. 결과 화면은 **판단 궤적** 패턴.

## 0-1. 신규 일반 원칙 (이 게임에서 확립, 이후 게임에 적용)

> **추가 확인권은 판단을 검증하거나 더 깊게 만드는 자료를 열어야지, 올바른 판단에 필수적인 핵심 사실을 잠그면 안 된다.**
> 기본 자료 = 해당 라운드의 역사적 판단에 반드시 필요한 증거 / 추가 확인권 = 그 판단을 검증·심화하는 증거.

## 1. 라운드 문법 (전 라운드 공통)

```
예측 (잠금) → 기본 증거 공개 → [추가 확인권 사용?] → 판단 척도 입력 → 다음 라운드
```

- **예측은 행위다(v1.4):** 슬라이더형 라운드(R2·R4)는 초깃값을 화면에 보여주되 저장하지 않는다. 학생이 실제로 조작해야 예측이 성립하고 확정 버튼이 열린다. 선택형(R1·R3)과 행위 강도를 맞춘다.
- **추가 확인권: 게임 전체 2개.** R1~R3에서만 사용 가능 (R4는 추가 자료 없음).
- **사전 고지(v1.2):** R1 진입 시 1회 안내 — "경찰·정치 참여·치안 유지법 자료에서 추가 확인 기회가 한 번씩 주어집니다. 확인권은 2개입니다." 기회 총수를 알아야 '3곳 중 어디 두 곳을 깊게 볼 것인가'라는 배분 판단이 성립한다. 분야명은 수업 내용이라 답을 누설하지 않는다.
- 사용하지 않은 확인권의 자료는 **에필로그에서 전부 공개** — 학습 결손 없음.
- 확인권 사용 여부·위치는 데이터로 수집.

### 판단 척도 (매 라운드, 증거 확인 후 1탭) — v1.2 교체

> **지금 확인한 자료를 볼 때, 통치 방식의 변화가 실제 식민 지배의 완화로 이어졌다고 볼 수 있습니까?**

`대체로 완화로 이어졌다 — 일부 완화로 이어졌다 — 완화로 이어졌다고 보기 어렵다 — 오히려 통제가 강화된 모습이다`

- 중립값 없는 4점 척도. "완전히" 계열 표현 금지 (보통 경찰제 전환 등 실재한 변화의 판단 여지 보존).
- **폐기된 문구:** "발표와 실제가 얼마나 일치했는가" — 사이토 발표문은 경찰 규모 축소를 약속한 적이 없고, 치안 유지법(1925)은 발표문의 약속 항목이 아니다. '일치도'를 물으면 이중 예측에서 제거한 허수아비가 되살아난다.
- '신뢰도' 개념도 폐기(태도 측정). 측정 대상은 **변화의 의미에 대한 증거 기반 해석**.
- 네 라운드가 모두 같은 질문을 받는다: R1 제도 전환↔경찰력 확대 / R2 참여 통로↔대상·권한 제한 / R3 치안 유지법·구속 확대 / R4 임용 가능↔실제 0명

## 5. 데이터 계약 (Supabase — 표준 준수)

```
game_results: class / game='saito1919' / choices(jsonb) / comment / timestamp
```

choices 구조 (**확정 — 코드는 어댑터로 이 형태를 맞춘다**):
```json
{
  "record_type": "result",          // 'result' 즉시 전송 / 'comment' 복사 시
  "version": "1.0",
  "initial": "완화|형식|유보",
  "r1": {"dir": "늘었다", "scale": 1-4},
  "r2": {"pct": 10, "scale": 1-4},
  "r3": {"shape": "...", "scale": 1-4},
  "r4": {"count": 0, "scale": 1-4},
  "tokens": ["r1", "r3"],           // 확인권 사용 위치 (0~2개)
  "final": 1-4,                     // ⚠ 1부터. 내부 인덱스 0~3을 +1 변환
  "final_axis": "지속성|통제재편|변화인정|증거한계",
  "changed_by": "r1|r2|r3|r4|none", // 처음 판단을 바꾼 자료 (학생 선택)
  "reason": "..."
}
```

- `r1.mag` 삭제 (v1.2 슬라이더 폐기에 따른 계약 정리)
- **전송 시점(v1.5):** `result`는 결과 화면에서 `changed_by`를 고른 뒤 **[이 선택을 기록한다]를 누른 시점**에 전송한다. 기록 전에는 자유롭게 재선택 가능, 기록 후에는 선택지가 잠긴다. 첫 탭 즉시 전송하면 재선택 시 result 레코드와 화면·복사·comment 값이 어긋난다. 기록 전에는 복사·에필로그 버튼도 잠긴다. `comment`는 종전대로 복사 버튼 클릭 시 별도 전송.
