## 상대적으로 약한 영역

- Management Simulation
- Resource Management
- Coalition / Faction Management
- Evidence Board 중심 게임
- Network Game
- Information Asymmetry 중심 게임
- Spatial Strategy
- 본격 Economic / Market System
- Emergent / Systemic Narrative

빈 영역을 채우는 것이 목표는 아니다.
기존 선택형 구조를 반복하기 전에 대안 후보로 검토한다.
