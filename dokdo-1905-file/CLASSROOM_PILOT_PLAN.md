# 독도연구소: 1905 파일 — 교실 사용성 파일럿 계획

목적: 기술적 browser QA가 아니라 **실제 학생이 설명 없이도 무엇을 해야 하는지 이해하고, 사료를 충분히 읽으며, 새 근거에 따라 판단을 수정하는지** 확인한다.

이 파일럿은 역사 정답률 시험이 아니다. 학생의 사료 읽기·조사 선택·판단 수정 경험이 DESIGN_LOCK대로 작동하는지 검수한다.

## 1. 권장 순서

가능하면 두 단계로 진행한다.

### 1차 소규모 파일럿
- 학생 3~6명
- 개인 또는 2인 병렬 플레이
- 교사는 직접 설명하지 않고 관찰 위주
- 화면 녹화가 필요하면 학교·학생 동의 절차를 먼저 따름
- 학생 이름·계정·개인 정치 의견은 기록하지 않음

### 2차 한 학급 파일럿
- 50분 수업 기준
- 도입 3~5분
- 게임 30~35분
- 전체 디브리핑 10~15분

1차에서 심각한 조작 혼란이나 역사 오독이 발견되면 2차로 바로 넘어가지 않는다.

## 2. 교사 도입 — 최소 개입

학생에게 게임의 정답이나 자료 역할을 설명하지 않는다.

도입에서는 다음만 안내한다.

> 여러분은 청소년 전시문을 검수하는 연구 인턴입니다. 화면에 제시되는 기록을 읽고, 필요한 자료를 골라 조사한 뒤, 새 자료가 들어오면 이전 판단을 그대로 둘지 수정할지 결정하세요. 모든 보조자료를 열 필요는 없습니다.

추가 설명은 조작 불능 상황에서만 한다.

## 3. 관찰 기록 방식

학생별 실명 대신 `A / B / C ...` 코드만 쓴다.

각 장면에서 다음 세 기호만 우선 기록한다.

- `○` — 설명 없이 진행
- `△` — 10초 이상 멈추거나 한 번의 교사 힌트 필요
- `×` — 무엇을 해야 하는지 이해하지 못해 직접 조작 설명 필요

그리고 실제 발화나 행동 중 설계 판단에 중요한 것만 짧게 메모한다.

예:

```text
B / S3 / △ — “석도면 독도라는 뜻인가?”라고 물었지만 화면을 다시 읽고 ‘추가 근거 필요’로 진행.
D / S6 / × — ‘A가 B를 보강’ 방향을 반대로 읽음. 관계 문구 재설계 필요.
```

## 4. 장면별 핵심 관찰

### S0 — 검수 시작

성공 신호:
- 60초 안에 첫 조작을 시작한다.
- 가공 전시문을 실제 사료로 오인하지 않는다.
- 왜 당대 문서를 확인하려는지 이해한다.

문제 신호:
- 어느 글자를 눌러야 할지 10초 이상 찾는다.
- 처음부터 ‘정답 문장 찾기’로 받아들인다.

### S1 — 1905 내각 결정

성공 신호:
- 본문을 읽고 서로 다른 기능의 구절을 골라낸다.
- 보조자료를 모두 열어야 한다고 생각하지 않는다.
- 현재 정부 설명과 1905년 당시 문서를 같은 자료로 보지 않는다.

관찰 질문 — 장면을 끝낸 뒤 필요할 때만:

> “방금 본 두 종류의 자료는 뭐가 달랐나요?”

학생이 `작성 시점 / 작성 주체 / 당시 문서와 현재 설명의 차이` 중 하나라도 자기 말로 설명하면 충분하다.

### S2 — 1877 지령과 지도

실제 `磯竹島略圖` asset 교체 후에 본격 판정한다.

성공 신호:
- 지령의 직접 문구와 지도 관찰을 별개 행동으로 이해한다.
- 지도에서 무엇을 봐야 하는지 30초 안에 찾는다.
- 현재 지명 식별을 원문에 적힌 말처럼 받아들이지 않는다.
- `식별 / 보류` 중 어느 것을 골라도 근거 강도 선택이라는 점을 이해한다.

문제 신호:
- 지도 hotspot 문구만 보고 이미 정답을 안다고 느낀다.
- “태정관 문서에 독도라고 쓰여 있다”고 이해한다.

### S3 — 1900 칙령 제41호

성공 신호:
- `석도`를 실제 원문 표기로 인식한다.
- `석도=현재 독도`를 즉시 확정하지 않고 추가 근거가 필요하다는 메모의 의미를 이해한다.

핵심 관찰:

> 학생이 이 장면을 ‘문제를 아직 못 풀었다’가 아니라 ‘의도적으로 판단을 보류했다’고 느끼는가?

### S4 — 선택 조사

성공 신호:
- 학생마다 실제로 여는 보조자료가 달라진다.
- “전부 열어야 다음으로 가나요?”라는 질문이 반복되지 않는다.
- 니타카 자료를 열었을 때 `기록한 주체 / 정보가 온 곳 / 기록된 명칭`을 분리한다.
- 군사·통신 자료를 즉시 단일 인과로 바꾸지 않는다.

선택 조사 검수에서는 **많이 연 학생이 더 잘한 학생으로 보이지 않게** 한다.

### S5 — 판단 수정

이 장면은 파일럿의 가장 중요한 관찰 지점이다.

성공 신호:
- 1906년 새 자료를 먼저 읽고 필요한 표현을 확보한다.
- S3의 옛 메모가 다시 등장했음을 알아차린다.
- 왜 수정하거나 보류하는지 자기 말로 설명할 수 있다.
- 수정 뒤에도 `1900년 원문은 석도`라는 제한을 유지한다.

장면 종료 후 짧게 묻는다.

> “왜 아까 메모를 다시 보게 됐나요?”

다음과 같은 취지면 성공이다.

> “뒤의 자료에서 독도라는 이름과 소속 표현이 더 나와서요.”
> “근거가 늘어서 전보다 더 강하게 말할 수 있어서요.”
> “그래도 1900년 문서 자체에는 석도라고 써 있어서요.”

정해진 문장을 외울 필요는 없다.

### S6 — 연구 보드

성공 신호:
- `자료 A를 주어로 읽는다`는 규칙을 추가 설명 없이 이해한다.
- 관계 라벨이 단순 장식이 아니라 두 자료를 어떻게 연결할지에 대한 판단으로 쓰인다.
- 최소 2개의 관계를 만들 때 무작위 조합을 하지 않는다.

문제 신호:
- A/B 방향을 반복해서 거꾸로 읽는다.
- `보강 / 후속 대응 / 시대 배경`의 차이를 전혀 구분하지 못한다.
- 관계를 만들기 위해 실제로 읽지 않은 자료가 필요하다고 느낀다.

### S7 — 전시 패널

성공 신호:
- 앞에서 자신이 확보한 메모가 재료로 돌아왔다는 것을 인식한다.
- 미리 주어진 모범답안을 고치는 느낌보다 자신의 조사 결과를 편집한다는 느낌이 든다.
- 주의 문구에 ‘현재 근거로 어디까지 말할 수 있는가’를 반영한다.

문제 신호:
- 자유 입력 자체가 막혀 전시 편집보다 작문 시험처럼 느낀다.
- 앞의 조사 선택과 무관한 문장을 새로 써야 한다고 느낀다.

## 5. 학생 종료 질문 — 3개만

게임 직후 개별 또는 전체로 세 가지만 묻는다.

1. **“처음 생각과 가장 많이 달라진 지점은 어디였나요?”**
2. **“안 열어본 자료가 있었나요? 왜 그 자료는 안 봤나요?”**
3. **“이 게임에서 확실히 말할 수 있는 것과 조심해서 말해야 하는 것은 각각 무엇인가요?”**

`재미있었나요?`만으로 설계를 판정하지 않는다. 필요하면 별도 만족도 질문을 추가할 수 있지만 위 세 질문보다 우선하지 않는다.

## 7. 파일럿 통과 기준

### 치명적 문제 — 하나라도 있으면 수정 후 재시험

- 학생이 `1900년 칙령에 독도라고 직접 적혀 있다`고 게임 때문에 오해함
- 학생이 `1877년 지령 한 장이 오늘날 영유권 문제를 최종 해결한다`고 게임 때문에 오해함
- 학생이 `러일전쟁/전신소 조사가 1905 편입의 유일한 직접 원인`이라고 게임 때문에 오해함
- S5의 판단 수정이 사실상 자동 정답 선택으로 느껴짐
- 핵심 장면에서 다수 학생이 교사 설명 없이는 진행 불가

### 주요 수정 필요

- 같은 장면에서 학생의 절반 이상이 10초 이상 ‘무엇을 눌러야 하나’를 찾음
- 대부분 학생이 보조자료를 모두 열어야 한다고 오해함
- S6 관계 방향/라벨을 절반 이상이 잘못 읽음
- S7이 조사 결과 편집이 아니라 별도의 작문 과제로 느껴짐
- 전체 플레이가 대다수에게 40분 이상 걸림

### `tested` 승격 후보

아래를 모두 만족할 때만 manifest의 다음 상태를 논의한다.

- [ ] S2 실제 지도 asset이 들어가 있음
- [ ] 위 치명적 역사 오독 없음
- [ ] S0~S7 핵심 행동을 대다수 학생이 교사 개입 없이 수행
- [ ] S5에서 대다수 학생이 ‘새 자료 때문에 이전 판단을 재검토했다’는 취지를 설명
- [ ] 선택 조사에서 실제 경로 차이가 관찰됨
- [ ] S6 관계 방향이 이해됨
- [ ] 30~35분 범위에서 대다수 완주
- [ ] 교사가 디브리핑에 결과 화면/자료 선택 차이를 실제로 활용 가능하다고 판단

기술 QA가 통과했다는 이유만으로 이 체크를 자동 완료 처리하지 않는다.
