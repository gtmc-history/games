## 확인된 이용조건

### 일본 국립공문서관 Digital Archive
- `日本海内竹島外一島地籍ニ編纂方伺`의 catalog locator: `公02032100-01600`.
- National Archives of Japan Digital Archive는 제공 디지털 콘텐츠를 **영리·비영리 구분 없이 자유롭게 복제·개변·재배포**할 수 있고, 2차 이용 신청·절차가 필요 없다고 안내한다.
- 공개 매체에서는 `국립공문서관 소장`, 자료명, reference code, URI 등 출처 명시가 권장된다.
- 따라서 **1877 태정관 지령/기죽도약도는 외교부 홈페이지 이미지를 복제하는 대신 일본 국립공문서관 원 공개본을 정식 asset 출처로 사용**한다.
- 공식 도움말에서 IIIF manifest URI 형식은 `https://www.digital.archives.go.jp/api/iiif/[Image identifier]/manifest.json`임을 확인했다.
- 현재 남은 blocker는 저작권이 아니라 **item 3018187에 대응하는 image identifier/공식 다운로드 URI를 현 자동화 환경에서 안정적으로 추출하지 못한 것**이다. `/img/3018187` 경로는 현재 자동 접근에서 403이며, 제3자 복제본으로 대체하지 않는다.

### JACAR / 방위성 방위연구소 자료
- JACAR는 국립공문서관·외교사료관·방위연구소의 디지털 이미지를 제공하지만 이미지의 2차 이용 조건은 원 소장기관에 따라 다르다.
- 니타카·쓰시마 일지는 방위성 방위연구소 소장 자료이므로, JACAR에서 열람된다는 사실만으로 공개 웹게임 저장소 복제를 허용된 것으로 간주하지 않는다.
- 쓰시마 자료의 정본 식별자는 `C09050402800`으로 유지한다. 1904-11-20의 리앙코르드섬 유선 전신소 설치 적합성 조사 사실은 문서 단위로 검증했지만, 정확한 스캔 프레임 번호가 확인되기 전까지 번호를 추정해 문서화하지 않는다.

### 국사편찬위원회 한국사데이터베이스
- 공식 저작권정책은 홈페이지 자료 전반이 저작권 보호 대상임을 전제로 하며, 국사편찬위원회가 전부의 권리를 보유하거나 이용 동의를 받은 저작물만 일정 조건 아래 자유이용할 수 있다고 안내한다.
- 위원회가 권리 전부를 갖지 않은 자료와 외부 기관·개인이 제공한 자료는 원 권리자의 허락이 필요할 수 있다.
- 따라서 공개 웹게임에서는 **역사적 원문 자체의 검증된 전사와 정본 링크**를 우선 사용하고, 한국사DB가 제작·서비스한 스캔 이미지·현대 번역·해설을 자동으로 저장소 asset에 복제하지 않는다.
- 1900 관보 및 1906 행정문서는 현재 `source-overrides.js`에서 학생용 현대어 재구성과 역사적 원문 핵심구절을 분리해 제시한다.

### 대한민국 외교부 독도 홈페이지
- 사이트는 홈페이지의 모든 권리가 외교부에 귀속된다고 안내하고, 일부 배포 PDF에는 무단 전재·복제를 금지한다고 명시한다.
- 따라서 외교부가 제공한 사료 이미지는 단순히 다운로드해 게임 asset으로 포함하지 않는다. 텍스트 정보와 링크를 사용하고, 이미지가 필요하면 원 소장기관의 공개본·이용조건을 우선 확인한다.

## 규칙

- 이용조건을 확인하지 않은 이미지는 저장소에 복제하지 않는다.
- 외부 링크는 원문 확인 보조 기능일 뿐, 핵심 Gameplay의 필수 네트워크 의존성으로 만들지 않는다.
- 사용권이 불확실하면 자체 제작 전사·도식과 정확한 출처를 사용한다.
- 이미지를 편집·크롭하면 가공 사실을 명확히 밝힌다.
- `학생용 현대어 재구성`, `당대 원문 핵심구절`, `현대 정부·연구 해설`을 서로 다른 정보층으로 표시한다.
- 이미지가 들어오더라도 학생에게 A/B 등급이나 내부 source ID를 노출하지 않는다.
