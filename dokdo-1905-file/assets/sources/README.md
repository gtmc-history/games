## 확인된 이용조건

### 일본 국립공문서관 Digital Archive
- `日本海内竹島外一島地籍ニ編纂方伺`의 catalog locator: `公02032100-01600`.
- National Archives of Japan Digital Archive는 제공 디지털 콘텐츠를 **영리·비영리 구분 없이 자유롭게 복제·개변·재배포**할 수 있고, 2차 이용 신청·절차가 필요 없다고 안내한다.
- 공개 매체에서는 `국립공문서관 소장`, 자료명, reference code, URI 등 출처 명시가 권장된다.
- 따라서 **1877 태정관 지령/기죽도약도는 외교부 홈페이지 이미지를 복제하는 대신 일본 국립공문서관 원 공개본을 정식 asset 출처로 사용**한다.

### JACAR / 방위성 방위연구소 자료
- JACAR는 국립공문서관·외교사료관·방위연구소의 디지털 이미지를 제공하지만 이미지의 2차 이용 조건은 원 소장기관에 따라 다르다.
- JACAR 학습 페이지의 방위연구소 소장 자료 안내는 **이미지 2차 이용에 소장기관 신청이 필요**하다고 명시한다.
- 따라서 니타카·쓰시마 원문 이미지는 별도 허가가 확인되기 전까지 게임 저장소에 복제하지 않는다.

### 대한민국 외교부 독도 홈페이지
- 사이트는 홈페이지의 모든 권리가 외교부에 귀속된다고 안내하고, 일부 배포 PDF에는 무단 전재·복제를 금지한다고 명시한다.
- 따라서 외교부가 제공한 사료 이미지는 단순히 다운로드해 게임 asset으로 포함하지 않는다. 텍스트 정보와 링크를 사용하고, 이미지가 필요하면 원 소장기관의 공개본·이용조건을 우선 확인한다.

## 규칙

- 이용조건을 확인하지 않은 이미지는 저장소에 복제하지 않는다.
- 외부 링크는 원문 확인 보조 기능일 뿐, 핵심 Gameplay의 필수 네트워크 의존성으로 만들지 않는다.
- 사용권이 불확실하면 자체 제작 전사·도식과 정확한 출처를 사용한다.
- 이미지를 편집·크롭하면 가공 사실을 명확히 밝힌다.
- 이미지가 들어오더라도 학생에게 A/B 등급이나 내부 source ID를 노출하지 않는다.
