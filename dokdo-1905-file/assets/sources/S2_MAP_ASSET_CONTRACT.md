# S2 기죽도약도 asset contract

목적: `DESIGN_LOCK v1.0`의 S2를 바꾸지 않고, 현재 `DEV PLACEHOLDER`를 일본 국립공문서관 원 공개본 이미지로 교체하기 위한 구현 계약이다.

## 1. 정본과 문서 관계

- 일건 자료: `日本海内竹島外一島地籍ニ編纂方伺`
- 지도: `磯竹島略圖`
- 소장/제공: 일본 국립공문서관 Digital Archive
- Reference Code: `公02032100-01600`
- Item ID: `3018187`
- Catalog: `https://www.digital.archives.go.jp/item/en/3018187`
- Content viewer pattern: `https://www.digital.archives.go.jp/img/3018187#[page]`
- JACAR alternate locator: `A07060000300` — 『公文録』明治10年3月内務省伺（一)의 해당 일건 자료
- 별도 대조 locator: `A07060000100` — 『太政類典』의 `日本海内竹島外一島ヲ版図外トス`

### provenance 주의

`磯竹島略圖`를 단순히 **“태정관 최종 지령에 직접 첨부된 지도”**라고 부르지 않는다. 현재 확인한 문서 편철 관계에서는 이 지도는 1876년 시마네현이 내무성에 `日本海内竹島外一島地籍編纂方伺`를 제출하면서 `原由の大略` 등과 함께 낸 지도 자료이고, 이후 내무성 질의와 태정관 처리 문서가 같은 일건에 함께 편철되어 있다.

따라서 학생 화면에서는 다음 표현을 우선한다.

> 같은 일건 문서에 함께 편철된 시마네현 제출 지도 「기죽도약도」

또는 공간이 좁으면:

> 시마네현 제출 지도 「기죽도약도」

지도와 최종 지령의 직접적인 작성 주체·문서 단계는 다르다. 지도의 존재를 곧바로 태정관 최종 판단의 직접 근거 전체라고 단정하지 않는다.

## 2. 공식 이미지 확보 순서

국립공문서관 이용안내에 따르면 item 메타데이터는 `https://www.digital.archives.go.jp/item/[ID].json`으로 받을 수 있고, RDF/JSON의 `rdfs:seeAlso`에는 IIIF manifest URL, `owl:sameAs`에는 content URL, `foaf:thumbnail`에는 썸네일 URL이 들어간다. 따라서 다음 우선순위로 공식 이미지를 확보한다.

1. `https://www.digital.archives.go.jp/item/3018187.json`의 `rdfs:seeAlso` 확인
2. IIIF manifest에서 `磯竹島略圖`가 있는 실제 page/canvas와 image service 확인
3. 공식 content viewer `img/3018187`에서 페이지 번호 대조
4. 필요하면 JACAR `A07060000300`의 공식 뷰어로 같은 페이지를 교차 확인
5. 게임용 크롭을 원 공개본에서 제작

**금지:** 제3자 블로그·위키·논문에 재수록된 이미지를 canonical asset으로 대체하지 않는다. 문서 배열을 근거로 이미지 프레임 번호를 추정해서 기록하지 않는다.

## 3. 저장소 파일

공식 원 공개본을 확보한 뒤 아래 경로를 기본으로 한다.

```text
dokdo-1905-file/assets/sources/kijukdo-yakudo.jpg
```

가능하면 원본 전체를 그대로 넣기보다 S2에서 필요한 지도 부분만 읽기 좋은 해상도로 크롭한다. 크롭·회전·명암 보정이 있으면 학생 화면 캡션과 이 문서에 가공 사실을 기록한다.

## 4. 학생 화면 표기

이미지 아래 최소 표기:

> 1876년 시마네현 제출 지도 「기죽도약도」(1877년 태정관 처리 관련 일건 문서에 편철, 게임 화면용 크롭). 일본 국립공문서관 소장, `公02032100-01600`. 원 공개본에서 크롭·확대함.

학생 화면에는 `A07060000300`, QA ID, image identifier 같은 개발용 locator를 노출하지 않는다.

## 5. hotspot 데이터 계약

## 6. Gameplay 계약

실제 이미지가 들어와도 다음 순서는 바꾸지 않는다.

1. 학생이 태정관 지령 본문의 `죽도 외 1도` 직접 문구를 확인한다.
2. 같은 일건에 편철된 시마네현 제출 지도에서 hotspot 2개를 눌러 명칭·상대 위치 단서를 확보한다.
3. 두 단서를 확인한 뒤에만 현재 지명 식별 메모가 열린다.
4. 학생은
   - `지도 단서와 후대의 식별 해석을 연결해 현재 독도로 식별`
   - `현재 지명 식별 보류`
   중 하나를 선택할 수 있다.
5. 이 선택은 사실 정답이 아니라 해석 상태 `outside_one_status`로 저장한다.

즉 실제 지도 asset은 **식별을 자동 정답 처리하기 위한 이미지가 아니라, 해석에 필요한 단서를 학생이 직접 읽게 하는 자료**다.

## 7. UI / 접근성

- 이미지 자체는 `width: 100%; height: auto`로 비율 유지.
- hotspot 최소 실제 터치 영역: 44×44 CSS px.
- hotspot은 투명 버튼만 두지 말고 focus-visible outline과 선택 상태를 제공한다.
- 키보드 Tab → Enter/Space로 단서 선택 가능.
- hotspot의 `aria-label`은 `정답 독도`처럼 결론을 말하지 않고 `두 번째 섬의 명칭·상대 위치 확인`처럼 관찰 행동을 말한다.
- 이미지 로딩 실패 시 S2를 무응답 상태로 만들지 않는다. 출처 링크와 `이미지 불러오기 실패` 안내를 보여주되, release 전에는 local static asset이 정상 표시되어야 한다.
