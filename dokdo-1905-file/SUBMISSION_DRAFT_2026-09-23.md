# 독도연구소: 1905 파일 — 제출 원고 작업본

## 한 문장 소개
학생이 1877~1906년 독도 관련 기록을 직접 읽고, 새 근거가 등장할 때 이전 설명을 다시 열어 수정하며 청소년용 디지털 전시 패널을 완성하는 사료 탐구 게임 수업.

## 대상과 시간
- 고등학교
- 50분 1차시
- 도입 3~5분 / 게임 30~35분 / 디브리핑 10~15분

## 학습 목표
1. 당대 문서의 직접 문구와 후대의 식별·정부 해설·연구 해석을 구분한다.
2. 서로 다른 시점·작성 주체·문서 성격의 사료를 연결해 1905년 전후의 역사적 맥락을 설명한다.
3. 새 자료가 들어오면 기존 판단과 표현 강도를 수정한다.
4. 최종 전시문에서 현재 근거로 확실히 말할 수 있는 것과 추가 근거가 필요한 것을 구분한다.

## Core Sequence
- S0 검수 보류
- S1 1905 사건 파일
- S2 1877 태정관 지령 + 기죽도약도
- S3 1900 칙령 제41호의 석도
- S4 선택 조사: 니타카 / 쓰시마 등
- S5 1906 후속 기록 + 과거 메모 실제 수정
- S6 고정 시간축 연구 보드
- S7 학생이 실제 저장한 메모만으로 전시 패널 편집

## 역사 처리 원칙
- 1877 지령의 `죽도 외 1도` 직접 문구와 현재 지명 식별을 구분한다.
- 기죽도약도는 같은 일건에 편철된 시마네현 제출 지도 자료로 설명한다.
- 1900 칙령 원문은 `석도`로 유지하고 현재 지명을 괄호로 미리 넣지 않는다.
- 1904 니타카 자료는 명칭 사용 정보로 제한한다.
- 1904 쓰시마 자료를 1905 편입의 단일·직접 원인으로 처리하지 않는다.
- 1906 보고·지령은 문서가 직접 말하는 행정 소속 표현과 중앙정부 대응을 확인하는 자료로 사용한다.
- 현대 국제법적 최종 판단을 점수형 정답으로 만들지 않는다.

## 게임 설계 특징
- 모든 보조자료를 강제로 열지 않음
- 읽지 않은 자료는 연구 보드에 나타나지 않음
- 사실 오류는 교정하되 핵심 해석은 근거 강도와 한계로 피드백
- S5에서 과거 메모를 실제로 다시 열어 수정
- S7에서 미리 작성된 모범답안 대신 학생이 저장한 메모만 재사용

## 평가 및 관찰
- 당대 원문과 현대 해설의 출처 구분
- 사료가 감당하는 범위에 맞는 표현 강도
- 새 자료에 따른 판단 수정
- 자료쌍 관계 판단
- 자기 조사 결과 기반 전시 패널 완성

## 개인정보 최소화
- 구조화된 선택·수정 횟수·완료 여부 중심
- 자유서술 원문 및 정치적 성향 추정값은 서버 저장 대상에서 제외
- 저장 실패가 게임 완주를 막지 않음
