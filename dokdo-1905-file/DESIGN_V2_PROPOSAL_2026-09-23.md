## 1. 현재 설계(v1.0) 비판적 평가

### 강점 — v2에서도 반드시 지킬 것
1. **판단 이력이 상태로 남는다.** S5에서 S3의 *내 메모 자체*를 다시 열어 고치는 구조는 활동지로는 구현하기 어려운 이 게임의 존재 이유다.
2. **사실/해석/평가의 층위 분리**가 데이터·피드백 체계(정오 vs 근거 강도)로 이미 구현되어 있다.
3. **원문 표기 보존**(`석도`, `죽도 외 1도`, `본군 소속 독도`)과 과잉해석 금지선(A15 단일 원인 금지, 편철 지도 표현 등)이 명확하다.
4. **선택 조사 + 읽지 않은 자료는 보드에 없음** → 결과물이 학생마다 달라진다.
5. 점수·속도 보너스·국가 도덕 점수 없음. 민감 주제 규칙과 잘 맞는다.

### 약점 — v2가 실제로 해결해야 할 것
| 약점 | 근거 | v2의 대응 |
|---|---|---|
| **선택 조사에 “선택할 이유”가 약하다.** `추가 자료 열기` 버튼은 비용도 방향도 없어서 학생이 “전부 열기” 또는 “하나도 안 열기”로 수렴할 위험 | 버튼이 질문과 연결되어 있지 않음. 어떤 기관의 자료가 필요한지 고민하지 않아도 열 수 있음 | Hub에서 **질문 카드를 들고 출처 구역을 골라** 찾아가게 함 (§5) |
| **화면 문법이 S1~S4 내내 같다.** 공통 8블록 화면은 안정적이지만 4장면 연속이면 “디지털 학습지” 인상 | LOCK §6 공통 화면 고정 규칙 | Desk 문법은 유지하되, 장면 사이 전환을 공간 이동으로 바꿔 리듬을 만듦 |
| **캐릭터가 수동적이다.** 대화가 “다음 장면 예고”에 머묾 | VN Beat가 전환·도착에만 배치 | NPC를 **공간에 배치**하고 역할을 “되묻기·출처 안내·제약 제시”로 명확히 함 (§8) |
| **“되돌아가 고친다”가 화면 전환 하나로 처리된다.** 가장 중요한 S5 행동의 무게감이 약할 수 있음 | S5 수정은 모달/패널 안에서 일어남 | 연구 벽에 붙어 있던 **내 1900 메모를 직접 떼어 와서** 고치는 Mission (§6 S5) |
| **학생 사용성은 아직 미검증.** QA는 자동 브라우저 QA뿐 | `QA_BROWSER_REPORT`, `CLASSROOM_PILOT_PLAN`(미실시) | 위 약점들은 **설계자 추정**이다. 파일럿 데이터로 확인해야 함 (§12) |

> 주의: 위 약점 중 어느 것도 “조작형 공간 탐색”만이 유일한 해법은 아니다. 예컨대 첫 번째 약점은 Desk 안에서 질문 카드만 추가해도 절반은 해결된다. v2는 **공간 탐색이 같은 문제를 더 잘 푸는 경우에만** 공간을 쓴다.

## 2. 첨부 자료와의 정합

### 2-1. 2025 독도교육 내용체계(고등학교)와의 대응

| 게임 요소 | 내용체계 내용요소 / 성취기준 |
|---|---|
| S2 1877 | (62) 태정관지령과 기죽도약도(1877), [12독도-06-01] 문헌·지도 분석 |
| S3 1900 | (25) 석도(石島), (41) 대한제국 칙령 제41호(1900) |
| S1·선택 | (78) ‘시마네현 고시 제40호’(1905) |
| S5 1906 | (43) 심흥택보고서·이명래보고서·참정대신 박제순 지령 3호(1906), (72) 심흥택 |
| S5 핵심 | **[12독도-07-01]** 대한제국 시기 일제의 독도 침탈 과정과 **지방 및 중앙 정부의 대응** 조사·탐구 — S5의 `본군 소속 독도 / 일본 측 통보 / 의정부 대응` 분리가 이 성취기준과 정확히 겹친다 |
| S4-B | 고교 목표 “국제질서의 변화 속에서 독도가 지니는 역사적·지리적·정치적·**군사적** 의미를 종합적으로 탐구” |
| 전체 | 고교 목표 가. “관련 자료를 **비판적으로 탐구 및 해석**하는 능력” |

**긴장점과 처리 원칙**
- 내용체계는 `돌섬(석도)`, `시마네현 고시 제40호의 불법성`처럼 **결론을 포함한 표현**을 내용요소로 쓴다. 게임은 이 결론을 부정하지 않는다. 다만 **학생 화면에서 원문을 결론으로 치환하지 않고**, 학생이 후속 자료로 연결을 강화하는 과정을 거치게 한다(v1.0 LOCK §12 유지). 결론 수준의 정리는 **교사 디브리핑**의 몫으로 명시한다.
- 내용체계 중학교 내용요소 `‘시마네현 고시 제40호’와 ‘대한제국 칙령 제41호’ 비교`(고교에서는 심화 전제)는 v2 S6 연구 벽에서 **자료쌍 추천 없이** 학생이 스스로 고를 수 있는 대표 연결로 자연스럽게 등장한다(두 자료를 모두 열었을 때).
- [12독도-07-02] (1905 이후 자료에 한국 영토로 표시된 사례)는 1877~1906 범위를 벗어나므로 **본편에 넣지 않는다.** 확장 차시 후보로만 기록.
- 내용체계 “담당 교사는 **1~2차시 내외**로 선정·재구성” 권장 → 1차시(50분) 완결 설계를 유지한다.

### 2-2. 통합사회② 수업지도안(지리 중심)과의 관계
- 지도안은 `위치·거리(울릉도/오키)·영해·EEZ·지정학적 가치 → 홍보 안내문 PBL`이다. 이 게임과 **주제는 같지만 학습 목표 층이 다르다**(지리·영역 vs 사료·판단).
- 게임 안에 지리 탐구를 억지로 넣지 않는다. 대신
  - 수업 흐름: `통합사회 지리 차시(위치·영역)` → `본 게임(역사 사료 차시)` 연계 가능성을 README의 교사 안내에 적는다.
  - 산출물 대비: 지도안의 **홍보 안내문**은 “알리는 글”, 게임의 **전시 패널**은 “근거 범위를 검수한 글”이다. 디브리핑에서 두 글쓰기의 차이(표현 강도·근거)를 비교하는 발문으로 활용할 수 있다.
- 게임 연구소의 지도 테이블은 **1877 기죽도약도 전용**으로 두고, 현대 지도·EEZ를 넣지 않는다(시간 예산 + 층위 혼동 방지).

## 3. 구조 비교

| 기준 | A. 전체 RPG 탐색 | B. Hub + Desk 2층 | C. 일부 장면만 조작형 | **추천 B′+C** |
|---|---|---|---|---|
| 사료 읽기 시간 보존 | ✗ 이동·대화가 잠식 | △ 장면마다 Hub를 거치면 반복 이동 | ○ | **○ Hub는 선택 조사에만** |
| 선택 조사의 의미 강화 | ○ | ○ | △ 조작 장면에 조사가 없으면 무관 | **○** |
| 조작 문법 일관성 | ○ | ○ | ✗ 어떤 장면만 걷는 이유가 불분명 | **○ “Hub=자료실”, “Mission=되돌아가기·찾아 넣기”로 규칙화** |
| 30~35분 준수 | ✗ | △ | ○ | **○ (§7)** |
| 390px 모바일·크롬북 | ✗ 가상패드·정밀조작 | △ | ○ | **○ 탭 이동 + 이동 OFF** |
| 민감 주제 톤 | ✗ “독도를 지켜라” 퀘스트화 위험 | ○ | ○ | **○** |
| 기존 구현 재사용 | ✗ 재작성 | ○ | ○ | **○ S0~S7 Desk 코드 유지** |
| 제작 비용 | 매우 큼 | 중 | 중하 | **중** |

**A를 기각하는 이유 (핵심만)**
1. 30~35분 안에 핵심 사료 4묶음 + 선택 자료 읽기를 유지하면 이동·대화에 쓸 시간이 거의 없다. RPG 문법은 시간을 달라고 한다.
2. `걸어가기 → 말 걸기 → 줍기`가 성공 경험의 중심이 되면, 학생이 기억하는 것은 “어디에 문서가 있었나”이지 “그 문서가 무엇을 말할 수 있나”가 아니다.
3. 영토 주제를 액션/퀘스트 문법으로 감싸면 “사료 검수”가 “임무 수행·수호”로 읽히기 쉽다. v1.0이 피한 톤이다.

**B 단독이 부족한 이유**: 모든 장면 사이에 Hub를 끼우면 장면 선택권이 없는 곳에서도 걸어야 한다 → 메뉴를 걷게 만든 것과 같다.

**C 단독이 부족한 이유**: 조작 장면이 흩어져 있으면 학생에게 “왜 여기서만 걷지?”가 생긴다.

**B′+C**: 걷는 행위는 두 가지 뜻만 가진다.
- **Hub에서 걷기 = 어떤 출처가 필요한지 고르는 것** (선택 조사)
- **Mission에서 걷기 = 기록이 실제로 어디에 묶여 있는지/내가 전에 쓴 판단이 어디 있는지 찾아가는 것** (S2 편철, S5 되돌아가기)

## 4. 설계 원칙 — “장식이 아니라 탐구 메커니즘”이 되기 위한 조건

1. **공간 = 출처.** 구역은 문서의 작성 주체·시대로 나눈다. 자료의 *역할*(직접 근거/배경 맥락 등)로 나누지 않는다 — 역할은 학생이 판단한다(v1.0 §12 v0.7 규칙 유지).
2. **벽 = 시간.** 연구 벽은 1877 → 1900 → 1904 → 1905 → 1906 고정 시간축. 학생 메모는 해당 연도 칸에 핀으로 꽂힌다. S6 연구 보드는 이 벽 그 자체다.
3. **인벤토리는 문서가 아니라 질문이다.** 학생은 `질문 카드`(최대 3장)를 들고 다닌다. 서가에 가면 그 질문과 관련된 기록 후보가 보인다. 문서를 모으는 게 목표가 아니라 질문을 닫는 게 목표다.
4. **책상은 두 칸.** 한 번에 펼칠 수 있는 긴 문서는 2개(v1.0 규칙)를 `열람 트레이 2칸`으로 디에제틱하게 만든다.
5. **이동은 탭 한 번, 3초 이내.** 경로 탐색·길찾기 퍼즐·열쇠 찾기·수집품 없음. 두 번째 방문부터 구역 목록 점프.
6. **이동 OFF에서도 완주.** VN OFF와 같은 원칙. `이동 OFF`면 Hub가 구역 목록 화면으로 바뀌고 기능은 동일. (접근성, 저사양 크롬북, 교사 시간 단축 옵션)
7. **잠김은 역사 시간으로만.** 1906 서가는 “새 보고 도착” 전까지 `정리 중`. 퍼즐 성공 보상으로 문을 여는 구조는 쓰지 않는다.
8. **NPC는 결론을 말하지 않는다.** 허용: 되묻기, 출처 구역 안내, 전시 제약 제시, 학생식 오해 발화. 금지: 식별·인과·영유권 결론 문장 (§8).
9. **읽지 않은 자료는 벽에 없다.** Desk에서 실제로 펼친 문서만 벽에 카드로 생긴다(v1.0 유지, 이제 공간적으로 자연스러움).
10. **걷는 시간 ≤ 8%.** QA에서 `hub_elapsed / total_elapsed`를 측정하고 초과 시 설계 실패로 본다.

## 5. 공간 설계 — 「독도연구소 3층」

모바일 390px를 기준으로 **측면 시점 단일 복도(가로 스크롤)** 를 권장한다. 상하좌우 탑다운 맵보다 경로 탐색이 필요 없고, 가상 패드가 필요 없으며, 구현이 단순하다.

```
[① 검수실·내 책상] — [② 연구 벽 (1877│1900│1904│1905│1906)] — [③ 대한제국 문서고] — [④ 일본 공문서·해군 기록 서가] — [⑤ 현대 해설·연구 코너]
```

| 구역 | 들어 있는 것 | 누가 있나 | 주로 쓰는 장면 |
|---|---|---|---|
| ① 검수실·내 책상 | 전시 초안 모니터, Document Desk(열람 트레이 2칸), 기죽도약도 지도 테이블 | 박 기획자 | S0, 모든 Desk 읽기, S7 |

- 첫 60초 안에 조작

- 장면 사이 전환 방식(버튼 → 공간 이동)

- S6 보드의 시각적 메타포(카드 보드 → 연구 벽)

**새로 금지 (v2 LOCK 추가 후보)**
- 이동 시간 8% 초과, 길찾기·열쇠·수집품·타이머

**해석 한계**: 자동 플레이는 읽기 시간이 0이므로 측정표의 `이동 %`(자동 경로에서는 50% 이상)는 의미가 없다. 의미 있는 값은 **이동 절대 시간**이며, 학생이 선택 자료를 전부 여는 극단 경로(약 10회 이동 ≈ 10초)도 예산의 3% 안쪽으로 추정된다. 그러나 **학생이 서가 앞에서 머뭇거리는 시간, 구역을 출처 기준으로 이해하는지, 읽기 시간이 v1 대비 유지되는지는 자동 점검으로 알 수 없다** → §12의 학생 파일럿이 남은 게이트다.
