## 0. 두 참고 게임에서 가져올 것

실제 코드·화면을 열어 확인했다(`newsroom1945/`, `singanhoe1927/` payload 복원).

| | 1945 NEWSROOM | 지회의 4년 (신간회) | 독도 v1 / S4 Hub 프로토타입 |
|---|---|---|---|
| 무대 | **한 공간**(편집국)을 전면 일러스트 배경으로 | **한 공간**(지회 사무실) 전면 배경 | 흰 카드 UI / 도형 복도 |
| 인물 | 초상화 + 이름 + 2~3줄 대사, `계속 ›` | 큰 반신 일러스트, `스토리 연출 · 가상 인물` 표시, `건너뛰기` | 텍스트 박스, 초상 없음 |
| 문서 | 장면 **안에** 문서가 놓임(결정문 1~4항), 언제든 `📄 결정문 다시 보기` | 배경 위 종이 문서 + 우측 `읽을 문서` 목록 + 좌측 `내 기록` | 8블록 폼 화면 |
| 핵심 긴장 | **마감**: 내일 아침 1면 | **시간 경과**: 1927 → 1931, 4년 | 문장 검수 |

| 끝 | `FINAL EDITION` 인쇄 연출 | `당신이 남긴 4년의 기록` + `실제 역사` + `당시에는 알 수 없었던 기록` 분리 | 전시 패널 |
| 사운드 | ON/OFF | ON/OFF | 없음 |

**“날 것”의 원인은 공간 이동 여부가 아니라 세 가지다.**
1. **장소감이 없다** — 그림 한 장 없이 폼과 도형만 있다.
2. **인물이 얼굴이 없다** — 누가 왜 이 일을 시키는지 느껴지지 않는다.
3. **긴장이 없다** — 마감도, 시간 경과도, 누군가의 질문도 없다. 할 일 목록만 있다.

두 참고작은 조작 자체는 단순하다(선택·기록·비교). 대신 **한 장소 · 몇 명의 얼굴 · 하나의 긴장(마감/시간)** 으로 몰입을 만든다. 독도 게임도 걷는 Hub보다 이쪽이 투자 대비 효과가 크다.

## 1. 이 주제만 가진 게임 재료

VN 껍데기에 무엇을 넣을지는 주제 안에서 찾는다. 1877~1906 독도 기록에는 다른 주제에 없는 재료가 있다.

| 재료 | 사료상 사실 | 게임이 될 수 있는 이유 |
|---|---|---|
| **이름이 계속 바뀐다** | 1877 일건: `竹島(=磯竹島)`와 `松島`, 지령 `竹島外一島` / 1900 칙령 `石島` / 1904 니타카: 한국인 `獨島`, 일본 어부 `リヤンコ島` / 1905 내각·고시: 섬을 `竹島`라 명명 / 1906 보고 `本郡所屬獨島` | **같은 `竹島`가 1877년엔 울릉도, 1905년엔 지금의 독도를 가리킨다.** 학생이 직접 발견하면 강한 “아하”가 된다. 추리 게임의 핵심 퍼즐감이다. |
| **좌표와 거리** | 1905 시마네현 고시에 `北緯三十七度九分三十秒 東經百三十一度五十五分 … 隠岐島ヲ距ル西北八十五浬` / 기죽도약도에 오키·松島·磯竹島의 거리·방향 표시 | 이름이 흔들릴 때 **위치 정보가 식별 근거**가 된다. 지도 위에 찍어 보는 조작이 가능하다. |
| **말한 사람이 다르다** | 1906 보고 안에 `본군 소속 독도`(보고자 표현)와 `독도가 이제 일본 영지가 되었다`(일본 관리가 했다고 보고된 말)가 같은 문서에 섞여 있다 | 같은 종이 위 문장의 **화자를 가르는** 조작. |
| **당시에는 몰랐다** | 1905 편입 결정은 1906년 3월 일본 관리의 방문으로 울도군에 알려졌다 | 신간회식 `당시에는 알 수 없었던 기록` 분리 연출, 시점 교차에 적합. |
| **현재의 해설이 따로 있다** | 현재 일본 외무성의 “주권 재확인” 설명 ≠ 1905 결정문 | NEWSROOM의 `결정문 vs 보도` 대조 구조와 같은 모양. |

## 3. 세 가지 콘셉트 방향

### 방향 A 「개막 전야」 — NEWSROOM형 마감 VN
- **무대**: 청소년 독도 전시 개막 사흘 전, 밤의 전시 준비실(한 공간). 벽에 걸린 교정지 패널 한 장.
- **핵심 요소**: E2 교정지 + E4 마감 + E3 감수 질의 + E9 공간 예산
- **흐름**: D-3 문제 문장 발견 → D-2 1905·1877 추적 → D-1 1900·1904·1906 → 개막 아침 감수 질의 → 패널 인쇄
- **장점**: 참고작과 같은 문법이라 학생·교사 모두 익숙함. 구현 위험 가장 낮음.
- **약점**: NEWSROOM과 너무 닮아 새로움이 적다. 이 주제만의 퍼즐감이 부족하다.

### 방향 B 「두 개의 책상」 — 2026 × 1906 시점 교차
- **무대**: 현재의 연구소 책상 ↔ 1906년 울도군청(가상 서기의 책상)
- **핵심 요소**: E6 시점 교차 + E5 기록 재소환 + E7 화자 가르기
- **흐름**: 현재에서 사료를 읽다가, 막간마다 1900년(칙령 도착)·1906년(일본 관리 방문 소식) 울도군청으로 컷. 과거 장면에서는 **그때 알 수 있던 것만** 보이고, 현재로 돌아오면 후대 자료로 대조.
- **장점**: 몰입이 가장 강하다. `당시 시점 vs 오늘의 해석` 구분이 연출만으로 자연스럽게 체득된다.
- **약점**: 민감 주제 리스크가 가장 크다(실존 사건 현장 연출). 배경·인물 에셋이 가장 많이 든다. 과거 장면은 **관찰 전용**이어야 해서 조작이 적다.

### 방향 C 「이름을 잃은 섬」 — 명칭 추리 중심
- **무대**: 연구소 자료실. 벽에 거대한 **명칭 대조표**.
- **핵심 요소**: E1 명칭 대조표 + E8 지도 위치 + E5 재소환
- **흐름**: 문서를 읽을 때마다 새 이름이 등장하고, 표의 칸이 늘어난다. `竹島` 칸이 두 번 나타나 **1877의 竹島 ≠ 1905의 竹島**를 스스로 발견하는 순간이 중반 클라이맥스. `石島` 칸은 1904 니타카, 1906 보고, 현대 지명 연구를 붙이며 근거 강도가 올라간다.
- **장점**: 이 주제만의 게임이다. 사실/해석 층위가 퍼즐 규칙 그 자체가 된다.
- **약점**: 서사 긴장(누가, 왜)이 약하다. 퍼즐만 남으면 학습지처럼 보일 수 있다.

### 추천: **A의 껍데기 + C의 심장 + B의 막간 1회**

> **「개막 전야」의 마감 VN 안에서, 핵심 퍼즐은 `명칭 대조표`, 감정적 정점은 1906년 울도군청 1분 막간, 마지막 관문은 `감수 질의`.**

- A에서: 한 공간, 마감(D-3→개막), 살아 있는 교정지, 인쇄 엔딩 → **몰입과 틀**
- C에서: 명칭 대조표 → **이 주제만의 퍼즐**
- B에서: 막간 1회만(1906.3 울도군청, 관찰 전용, 60~90초) → **감정적 정점**, 리스크 최소화
- 걷는 Hub(E11)는 **보류**. 장면 전환은 배경 컷으로 한다.

### 명칭 대조표 규칙 (E1을 역사적으로 안전하게 만드는 조건)
1. 칸은 `문서 · 연도 · 적힌 이름 · 가리키는 섬 · 근거 종류 · 근거 강도`.
2. `적힌 이름`은 **사실층**이다 → 정오 피드백 가능(“원문에는 `石島`라고 적혀 있다”).
3. `가리키는 섬`은 **해석층**이다 → 정답 체크 없음. 대신 근거 종류가 쌓일수록 `근거 강도` 막대가 올라간다. 예:
   - 1905 `竹島` ↔ 지금의 독도: 고시의 **좌표**가 직접 근거 → 강함
   - 1877 `竹島` ↔ 울릉도: 일건 문서와 지도의 `磯竹島` → 강함
   - 1877 `外一島` ↔ 지금의 독도: 지도의 `松島` 위치 + 후대 식별 → 중간~강함, `보류`도 정당
   - 1900 `石島` ↔ 지금의 독도: 3막엔 근거 없음(보류만 가능) → 니타카·지명 연구·1906 보고로 올라감
4. 학생이 해석을 칸에 넣을 때 **근거 카드를 최소 1장 붙여야** 한다. 근거 없이 넣으면 `보류`로만 둘 수 있다.
5. 1877 `竹島`와 1905 `竹島` 칸은 **자동으로 합쳐지지 않는다.** 학생이 “같은 이름, 다른 섬”이라고 표시해야 발견 연출이 나온다.

### 감수 질의 규칙 (E3)
- 질의자는 **우리 전시팀의 감수위원**(가상). 일본 측 인물·국가 대표 캐릭터는 없다.
- 정답이 `증거 제시`인 질의와 **`이 자료로는 말할 수 없다`가 정답인 질의**를 섞는다(과잉 주장을 스스로 깎는 경험).
- 사실층 질의에만 즉시 정오. 해석층 질의는 “이 근거라면 문장을 어느 강도로 쓰겠나?”로 이어진다.

### 빠진 것 — 보완 필요
- **1905가 빠져 있다.** 이 안은 1877부터 시작하지만, v1 핵심 사료 1묶음(1905 내각 결정)과 “1905에서 거꾸로 추적”하는 도입 궁금증이 사라진다. → 프롤로그(문제 문장 표시) + 1905 결정문을 앞에 유지한다. `竹島(1905)` 카드가 여기서 먼저 생겨야 1877의 `竹島`와 만났을 때 “같은 이름, 다른 섬” 발견이 성립한다.
- **`竹島`는 세 번 나온다.** 1877 일건(울릉도 = 磯竹島), 1900 칙령 `鬱陵全島와 竹島 石島`의 `竹島`(울릉도 옆 부속 섬으로 해석), 1905 명명(지금의 독도). 카드를 문서별로 분리하지 않으면 학생이 셋을 한 섬으로 오해한다. 반대로 분리하면 이 게임 최고의 퍼즐 재료가 된다. 1900 `竹島`의 대상도 해석층으로 둔다.

### 항로 재구성 필수 조건 (실제 스캔 확인 결과)
저장소의 로컬 스캔 `assets/sources/kijukdo-yakudo.jpg`를 직접 열어 봤다. 지도에는 `磯竹島`(좌상), 작은 섬(중앙), `隠岐 島後`(우하), `朝鮮國`(좌측 해안선), 방위표가 **이미 그려져 있고**, 섬 사이에 거리 주기(`八十里許 / 四十里許 / 五十里許`, `SOURCE_LOCATORS.md`)가 있다.
1. **섬 그림을 먼저 가려야 한다.** 지도가 다 보이는 상태에서 위치를 “복원”하면 따라 그리기가 된다. → 1단계는 섬이 가려진 바다 위에 **주기 문구만** 주고 배치하게 하고, 2단계에서 원래 지도를 오버레이한다.
2. **방향 문구는 고해상도에서 전사 검수 후** 쓴다. 현재 저장소는 거리 표기만 확인했고, 로컬 스캔 해상도로는 방향 문구를 확정할 수 없다.
3. `里`는 지도 제작 당시의 약식 거리다. **절대 거리 대신 비율·순서**(오키 → 작은 섬 → 磯竹島 순, 앞 구간이 뒤 구간의 약 2배)만 비교한다. 이 지도는 `略圖`다.
4. 오버레이 1층 = 지도 자체의 관계(사실층, 어긋남 표시 가능). 2층 = 현재 지명(해석층, 학생이 켤 때만, `後代의 식별` 표시).
