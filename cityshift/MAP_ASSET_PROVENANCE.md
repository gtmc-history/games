# cityshift 지도 자산 출처·사용 원칙

상태: Visual patch source sheet v1

이 문서는 「도시의 자리」의 지도 비주얼 패치에서 사용할 실제 지도 자료의 출처와 사용 범위를 기록한다. 역사 사실·인과 판단은 DESIGN_LOCK v1.0을 따른다. 이 문서는 Presentation Layer 자산 선택만 다룬다.

## 1. 공통 원칙

- 지도는 출처가 확인되는 실제 당시 지도 또는 오늘날의 공개 지도 데이터를 기준으로 제작한다.
- 실제 지도 원본이 너무 복잡한 경우, 위치·해안선·하천·철도·도시 위치 등 필요한 요소만 추출하여 수업용 오버레이를 얹는다.
- 지도 자체가 역사적 인과를 더 강하게 주장하지 않도록 한다.
- 철도·항만·행정 기능의 상대적 영향력을 선 굵기·도시 크기 등으로 암시하지 않는다.
- 사례 3 목포 지도에서는 영산강 및 나주↔목포 축을 시각적으로 강조하지 않는다.
- 학생이 그리는 인과선과 배경 지도 요소는 별도 레이어로 유지한다.

## 2. 전국 개관 지도

### 1934 「朝鮮鉄道略図」
- 제작: 조선총독부 철도 관련 기관
- 시기: 1934년 7월
- 용도: 화면 2 전국 개관의 역사 지도 기준 자료. 당시 철도망과 사례 위치를 확인하는 참고 자산.
- 공개본: Wikimedia Commons `File:1930s korea rail map.jpg`
- URL: https://commons.wikimedia.org/wiki/File:1930s_korea_rail_map.jpg
- 권리 상태: Commons에서 대한민국·일본 및 미국 Public Domain 근거를 제시함.
- 사용 방침: 전국 개관용 실제 지도 배경 후보 1순위. 학생 인과선과 혼동하지 않도록 채도/대비를 낮추고 사례 위치만 오버레이한다.

### 1936 「朝鮮鐵道略圖」
- 제작: 朝鮮総督府鉄道局
- 시기: 1936년 1월
- 원자료: 『朝鮮鉄道一班 昭和11年』 p.9
- 공개본: Wikimedia Commons `File:Railway map of Korea (1936).webp`
- URL: https://commons.wikimedia.org/wiki/File:Railway_map_of_Korea_(1936).webp
- 장점: 6,138×8,878 고해상도.
- 주의: Commons 설명은 일본의 Public Domain 근거는 명시하지만 미국 권리 상태 안내가 1934본보다 덜 명확하다.
- 사용 방침: 세부 위치 판독용 보조 기준. production 자산은 권리 상태를 추가 확인하기 전 직접 복제하지 않는다.

- 소장: 한국학중앙연구원 장서각
- 제작: 육지측량부
- 측도·제판: 1917년

사용 방침:

- 확인 전에는 실제 지형 관계를 토대로 수업용 배경을 재구성하고, 출처를 명시한다.

## 6. 오늘날 지도 대체안

장서각 원문 스캔의 재사용 조건이 production 배포에 적합하지 않으면, 오늘날 위치 기준은 OpenStreetMap 데이터로 제작한 정적 수업용 지도를 사용한다.

- 출처: OpenStreetMap contributors
- 라이선스: ODbL
- 안내: https://www.openstreetmap.org/copyright
- 필수 표기: `Map data © OpenStreetMap contributors · ODbL`
- 사용 방침: 현재의 세부 도로/상업시설 등 수업에 불필요한 요소는 제거하고 해안선·하천·철도·도시 위치만 남긴다. 역사적 철도·시기 정보는 별도 역사 자료를 근거로 오버레이한다.

## 7. 구현 결정

1. 화면 2 전국 개관은 1934 역사 철도지도를 우선 사용한다.
2. 화면 3~5는 장서각 당시 지형도를 역사적 기준으로 삼는다.
3. 원문 스캔의 직접 재사용 조건이 불명확한 동안에는 해당 이미지를 production에 그대로 삽입하지 않는다.
4. 지역 보드는 실제 지도에 근거해 제작하되, 학생 조작과 인과 판단을 위한 오버레이 레이어를 분리한다.
5. 각 화면 하단에 `지도 출처`를 표시하고, 상세 출처는 정보 패널에서 확인할 수 있게 한다.
6. Visual patch가 끝나기 전 games.manifest의 `cityshift` 상태를 `published`로 올리지 않는다.
