# cityshift 지도 자산 출처·사용 원칙

상태: Visual patch source sheet v1.1

이 문서는 「도시의 자리」의 지도 비주얼 패치에서 사용할 실제 지도 자료의 출처와 사용 범위를 기록한다. 역사 사실·인과 판단은 DESIGN_LOCK v1.0을 따른다. 이 문서는 Presentation Layer 자산 선택만 다룬다.

## 1. 공통 원칙

- 지도는 출처가 확인되는 실제 당시 지도 또는 오늘날의 공개 지도 자료를 기준으로 제작한다.
- 지도 자체가 역사적 인과를 더 강하게 주장하지 않도록 한다.
- 철도·항만·행정 기능의 상대적 영향력을 선 굵기·도시 크기 등으로 암시하지 않는다.
- 학생이 그리는 인과선과 배경 지도 요소는 별도 레이어로 유지한다.
- 지리 등록되지 않은 스캔·철도도 위에 임의 퍼센트 좌표로 도시 마커를 얹지 않는다.

## 3. 위치 등록 좌표

이 좌표는 배경 지도와 표시를 맞추기 위한 위치 기준이며 역사적 인과를 뜻하지 않는다.

- 대전: 36.3500, 127.3850
- 공주: 36.4500, 127.1170
- 이리: 현 익산역 일대 35.94167, 126.94583
- 구 나주읍: 금성관 일대 35.03389, 126.71694
- 광주: 35.16667, 126.91667
- 영산포: 옛 영산포역 일대 35.00528, 126.70667
- 목포: 34.79361, 126.38861

구 나주읍과 영산포처럼 실제 위치가 가까워 노드 버튼이 겹치는 경우, 지도상의 기준점은 정확한 위치에 남기고 버튼만 옆으로 이동한다. 이때 점선 leader로 버튼과 실제 기준점을 연결한다.

## 8. 장서각 원문 이미지 사용 제한

장서각 자료는 실제 위치·지형·철도 관계 확인용 기준 자료로 사용한다. 디지털장서각 사이트가 원문 열람·다운로드를 제공하더라도 원문 이미지의 production 재사용 조건은 별도 확인이 필요하므로, 확인 전에는 원본 스캔을 게임에 직접 삽입하지 않는다.

## 9. 구현 결정

1. 화면 2와 화면 3~5의 상호작용 배경은 좌표 등록 가능한 현재 위치도를 사용한다.
2. 당시 지도는 역사 검증 및 참고 링크로 제공한다.
3. 모든 도시 마커와 조작 노드는 동일 좌표 변환을 사용한다.
4. 가까운 지점은 실제 기준점을 고정하고 버튼만 offset + leader 처리한다.
5. 각 화면에 지도 출처를 표시한다.
6. 교사 직접 지도 검수가 끝나기 전 `published` 전환은 하지 않는다.
